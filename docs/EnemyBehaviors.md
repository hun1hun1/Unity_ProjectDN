# 적 행동 패턴

정리 기준일: 2026-10-20.

적마다 `EnemyBehavior` 에셋의 `Selection Mode`를 지정한다. 같은 BattleScene과 Enemy 컴포넌트를 사용하면서도 서로 다른 행동 선택 규칙을 적용할 수 있다.

적별 외형과 Animator를 가진 프리팹의 연결은 [적 프리팹과 전투 화면](EnemyPrefabs.md)을 참고한다. 전투 데이터의 `Behavior`가 생성한 적에 적용된다.

## 설정

1. Project 창에서 `Create → Enemy → Behavior`로 행동 에셋을 만든다.
2. `Actions`에 사용할 `EnemyAction` 에셋을 연결한다.
3. `Selection Mode`에서 `Sequential` 또는 `Random No Three Consecutive`를 고른다.
4. 적의 `BattleEncounterDefinition.behavior`에 해당 행동 에셋을 연결한다. 맵에서는 선택된 전투 데이터가 적에게 적용된다. 단독 전투에서는 Enemy의 `Behavior` 참조를 사용한다.

기존 에셋의 기본값은 `Sequential`이므로 기존 전투의 행동 순서는 유지된다. 기존 씬·프리팹·전투 에셋을 재생성할 필요는 없다.

## 고정 순서 — Sequential

등록한 순서대로 실행하고 마지막 행동 다음에는 첫 행동으로 돌아간다. 예를 들어 `[공격, 공격, 방어]`는 공격 → 공격 → 방어를 반복한다. 한 가지 행동만 등록하거나 같은 행동을 여러 번 배치하는 것도 허용한다. 빈 항목은 해당 차례에 행동하지 않고 다음 항목으로 넘어가는 기존 규칙을 유지한다.

## 무작위·3연속 금지 — Random No Three Consecutive

등록된 서로 다른 유효 행동 중 하나를 같은 확률로 선택한다. 같은 행동을 연속 2회 실행했다면 다음 추첨에서 그 행동을 제외한다. 다른 행동을 실행하면 연속 횟수는 1부터 다시 센다. 최대 2회 연속까지 허용하는 규칙이며, 반드시 번갈아 행동하는 것은 아니다.

같은 행동인지 여부는 `EnemyAction` 에셋 참조로 판단한다. 피해량이 다른 공격 에셋 둘은 서로 다른 행동이다. 모든 공격을 하나의 종류로 묶어 연속 사용을 제한하는 기능은 포함하지 않는다.

빈 항목은 제외하며, 같은 에셋을 여러 칸에 연결해도 후보 하나로 취급한다. 중복 등록을 출현 가중치로 사용하지 않는다. 행동별 가중치 설정도 이번 구현에는 포함하지 않는다.

3연속 금지를 지키려면 서로 다른 유효 행동이 최소 2개 필요하다. 행동이 없거나 한 종류뿐이면 전투 데이터 검증 또는 적 초기화에서 설정 오류로 처리한다. 후보를 찾을 때까지 반복 추첨하는 방식이 아니므로 후보 부족으로 무한 반복하지 않는다.

## 행동 예고와 실행 상태

전투 초기화 시 첫 행동을 선택하여 보관하고, 적 턴에는 예고한 그 행동을 실행한다. 실행 후 마지막 행동과 연속 횟수를 갱신하고 다음 행동을 선택한다. 전투가 끝나면 후속 행동을 추첨하지 않는다.

상태이상 변경은 예고한 행동의 수치만 갱신하며 행동을 다시 추첨하지 않는다. 같은 전투의 반복 연결이나 Enemy 컴포넌트의 비활성화·재활성화로도 다음 행동과 연속 횟수를 초기화하지 않는다. 전투 설정을 새로 적용할 때에는 순서·이력·예고를 초기화한다.

선택 방식과 행동 목록은 공유 `EnemyBehavior`에, 현재 순서·마지막 행동·연속 횟수·예고 행동은 각 `Enemy`에 보관한다. 같은 행동 에셋을 여러 적이 사용해도 실행 상태를 공유하지 않는다. 현재 예고는 읽기 전용 `Enemy.NextAction`으로 확인할 수 있다.

## 검증 범위

`Assets/Tests/Editor/EnemyBehaviorTests.cs`에서 기존 직렬화 에셋의 기본 순서, 고정 중복·단일 행동, 무작위 연속 제한, 중복·빈 후보, 잘못된 무작위 구성, 적 사이의 실행 상태 분리, 전투 재설정, 상태이상 갱신과 예고 유지 등을 검사한다. 실제 BattleScene에 진입하여 예고 표시와 실행 피해가 일치하는지도 검사한다.

행동 선택 방식 최초 구현 시 Unity 6000.0.77f1에서 전체 EditMode 테스트 384/384 통과, 실패·건너뛰기 0개를 확인하였다. 이 중 적 행동 패턴 테스트는 11개이며 실제 Play Mode 진입 검사도 포함한다. 결과는 `.utmp/enemy-behavior/full.xml`, 로그는 `.utmp/enemy-behavior/full.log`에 기록하였다. 이후 프리팹 통합 검증은 [적 프리팹과 전투 화면](EnemyPrefabs.md)의 검증 기록을 참고한다. 이 최초 검증에서는 별도의 수동 화면 검수와 실행 파일 빌드를 수행하지 않았다.
