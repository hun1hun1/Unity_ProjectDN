# 총알 전부 소모와 소모량 조건 효과

기존 카드는 변경하지 않습니다. 새 효과를 생성한 뒤 원하는 카드의 `Effects`에 연결합니다.

## 총알 전부 소모

Project 창의 **Create → Card → Effect → Spend All Ammo**로 `SpendAllAmmoEffect`를 생성합니다.
`Effects`에 총알을 소모한 뒤 실행할 효과를 순서대로 연결합니다.

- 이 효과가 실행되는 순간의 현재 총알을 전부 소모하고, 실제 소모량 N을 한 번 기록합니다.
- 총알이 0발이거나 실행할 하위 효과가 없으면 하위 효과를 실행하지 않습니다.
- 고정 효과는 소모량에 관계없이 한 번 실행됩니다. 총알 수만큼 반복하는 효과가 아닙니다.
- 앞선 효과가 장전한 총알도 포함합니다. 카드 자체의 필수 탄약을 이미 소모했다면 남은 총알을 소모합니다.
- 총알이 없을 때 카드 사용 자체도 막으려면 `CardData.Required Ammo = 1`, `Consume Required Ammo = false`로 설정합니다. 전부 소모는 `SpendAllAmmoEffect`가 담당하므로 이 설정으로 이중 소모를 피할 수 있습니다.

## 총알 수에 비례하는 피해와 방어도

기존 `DamageEffect`와 `BlockEffect`에 **Amount Mode**가 추가됩니다.

| 설정 | 의미 |
| --- | --- |
| Fixed | 기존처럼 Damage 또는 Block 값을 그대로 사용합니다. 기존 카드의 기본값입니다. |
| Per Spent Ammo | Damage 또는 Block 값에 현재 전부 소모 효과가 기록한 N을 곱합니다. |

예를 들어 `SpendAllAmmoEffect → DamageEffect(Damage = 5, Amount Mode = Per Spent Ammo)`는 총알 4발을 소모하면 기본 피해 20을 한 번 줍니다. 이후 발동 당시의 녹슬음·약점 노출·방어도 규칙을 적용합니다. 피해 5를 4번 주는 것과는 다릅니다.

`SpendAllAmmoEffect → BlockEffect(Block = 15, Amount Mode = Fixed)`는 1발을 소모하든 10발을 소모하든 방어도 15를 한 번 얻습니다.

전부 소모 효과 밖에서 소모량 컨텍스트가 없는 비례 효과는 N=0으로 계산합니다. 기존의 지정 장수 소모 효과인 `SpendAmmoBonusEffect`는 이 컨텍스트를 생성하지 않습니다.

## N발 이상 소모했을 때 추가 효과

**Create → Card → Effect → Spent Ammo Threshold**로 `SpentAmmoThresholdEffect`를 생성합니다.

- **Min Spent Ammo**: 추가 효과에 필요한 최소 소모량입니다. 1 이상으로 설정합니다.
- **Effects**: 조건을 충족하면 한 번 실행할 추가 효과입니다.
- `SpendAllAmmoEffect`의 하위에 연결합니다. 현재 보유 탄약이 아니라 그 전부 소모 효과에서 기록한 N을 확인하며, 추가 탄약은 소모하지 않습니다.
- 기준값과 같은 소모량도 발동합니다. 여러 조건을 넣으면 충족한 조건은 각각 실행됩니다.

예시 구성:

```text
CardData.effects
└─ SpendAllAmmoEffect
   ├─ DamageEffect: Damage 5, Per Spent Ammo
   ├─ BlockEffect: Block 10, Fixed
   └─ SpentAmmoThresholdEffect: Min Spent Ammo 4
      └─ ApplyStatusEffect: 원하는 대상과 상태이상
```

총알이 3발이면 기본 피해 15와 방어도 10, 4발이면 기본 피해 20과 방어도 10 및 추가 상태이상을 적용합니다.

하위에서 장전하더라도 바깥 효과가 기록한 N은 바뀌지 않습니다. 중첩한 전부 소모 효과는 자신의 소모량을 사용하고, 끝나면 바깥 소모량으로 돌아옵니다. 같은 카드나 효과 에셋을 여러 번 사용해도 소모량은 공유하지 않습니다.

## 지연·지속 효과와 종료

- **전부 소모 → 지연 → 비례/조건 효과**: 지금 소모한 N을 예약에 보존합니다. 발동할 때 새 탄약을 소비하거나 현재 탄약으로 N을 바꾸지 않습니다. 중첩 지연에도 N을 전달합니다.
- **지연 → 전부 소모 → 비례/조건 효과**: 지연 효과가 실제로 발동하는 순간의 총알을 전부 소모합니다.
- 지속 카드의 사용 시 하위 유지 효과는 해당 지속 카드에 종속되어 해제됩니다. 턴 시작 효과에 전부 소모를 넣으면 그 턴 시작에 새로 소모합니다.
- 효과 목록은 기존 순차 실행 경로를 사용하므로 멀리건 등 입력을 기다립니다. 전투 종료·비활성화·취소 시 소모량 컨텍스트를 정리하며, 소비한 탄약을 환불하지 않습니다.
- 순환 참조가 있는 전부 소모 효과는 총알을 소모하지 않습니다.

## 카드 설명

일반 전투 미리보기는 탄약 복사본에서 소모와 조건을 계산하며, 실제 총알·체력·상태는 변경하지 않습니다. 우클릭 상세창과 전투 밖 설명에서는 비례 수치를 `5 × N`처럼 원본 공식으로 표시합니다.

위 예시에서는 다음 토큰을 사용할 수 있습니다.

```text
총알 {spentAmmo:0}발을 모두 소모합니다. {ammoCondition:0}
적에게 {damage:0.0}의 피해를 주고 방어도 {block:0.1}을 얻습니다.
4발 이상 소모 시 추가 상태이상을 부여합니다. {spentAmmoCondition:0.2}
```

각 토큰의 숫자는 효과 배열 인덱스이며, 하위 효과는 점으로 구분합니다. 턴 시작 목록에서는 `turnDamage`, `turnBlock`, `turnSpentAmmo`, `turnAmmoCondition`, `turnSpentAmmoCondition`을 사용합니다.

예약 툴팁에 직접 작성한 `Description`은 해당 지연 효과의 하위 인덱스를 기준으로 계산하며, 이미 소모한 N은 예약된 값으로 표시합니다. 미래의 상태이상 배율은 적용하지 않습니다. 자동 요약은 비례 공식과 최소 소모 조건을 표시합니다.

## 검증

Unity 6000.0.77f1 전체 EditMode 테스트 **333개 통과, 실패·건너뜀 0개**입니다. 신규 24개 검증에는 전부 소모, 0발, 비례 계산의 단일 타격 처리, 최소 소모량 경계값, 복수 조건, 중첩 소모량 복원, 지연 예약, 원본 설명, 미리보기 부작용 방지, 지속 효과 해제, 대기 실행 폐기와 파괴된 플레이어 참조 처리가 포함됩니다.

결과 파일은 `.utmp/spend-all-full-suite-final.xml`입니다. 기존 카드·씬·프리팹과 메타 파일은 작업 시작 시점의 바이트를 보존했으며, 수정한 기존 소스의 인코딩과 줄바꿈을 유지했습니다. 별도의 수동 플레이 검수는 수행하지 않았습니다.
