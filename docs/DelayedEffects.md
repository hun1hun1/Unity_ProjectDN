# 턴 지연 효과

Project 창의 **Create > Card > Effect > Delay**에서 효과 에셋을 생성하고 카드의 `effects` 목록에 넣습니다. 기존 카드에는 지연 효과를 자동으로 추가하지 않습니다.

| Inspector 설정 | 의미 |
| --- | --- |
| Delay Turns | 이후 플레이어 턴 시작을 몇 번 맞이한 뒤 실행할지 설정합니다. 1 이상입니다. |
| Effects | 지연 시점에 순서대로 한 번 실행할 기존 CardEffect 목록입니다. |
| Description | 상태창 툴팁에서 보여줄 지연 부분 설명입니다. 비워 두면 기본 효과 요약을 사용합니다. |
| Icon | 예약 표시 아이콘입니다. 비워 두면 원본 카드 그림을 사용합니다. |

예를 들어 Delay Turns를 2로 지정하고 DamageEffect와 ApplyStatusEffect를 Effects에 넣으면, 사용한 턴에는 예약만 등록하고 두 번째 이후 플레이어 턴 시작에 피해 → 상태이상 순서로 실행합니다. 같은 카드 여러 장을 사용하면 각각의 예약과 남은 턴이 독립적입니다.

지연 수가 1 미만이거나 유효한 하위 효과가 없으면 예약하지 않습니다. 지연·탄약 조건의 하위 목록이 자기 자신 또는 서로를 순환 참조하는 구성도 예약하지 않습니다.

## 실행 시점

사용한 턴은 세지 않습니다. 5턴에 사용한 1턴 지연은 6턴 시작에, 2턴 지연은 7턴 시작에 실행됩니다. 시간(초)이나 프레임 수와 관계없이 플레이어 턴 시작을 기준으로 계산합니다.

턴 시작 순서는 상태이상 지속 시간 처리 → 코스트·방어도 초기화 → 매개체의 턴 시작 장전 → 지속 카드 턴 시작 효과 → 지연 효과 → 드로우입니다. 따라서 지연 효과로 얻은 방어도와 코스트는 초기화로 사라지지 않습니다. 같은 턴에 발동하는 예약은 등록 순서대로 실행합니다. 실행 중 새 예약이 생기면 그 예약은 자신의 N턴을 기다립니다.

코스트와 카드 자체의 필수 탄약은 사용 시 한 번만 지불합니다. Effects 안의 SpendAmmoBonusEffect는 실제 발동 시 탄약을 확인하고 소비합니다. 피해량·방어도·상태이상도 발동 당시 상태를 기준으로 처리합니다.

멀리건처럼 선택을 기다리는 효과가 있으면 선택이 끝난 뒤 다음 효과를 실행합니다. 지연 발동 중에도 기존 효과 실행 입력 잠금을 사용합니다. 턴 시작에는 손패를 버린 뒤 드로우하기 전이므로 멀리건 후보가 없을 수 있습니다.

## 카드 위치와 소멸

- 공격·스킬은 사용 후 기존 규칙대로 버림/소멸 더미에 들어갑니다. 예약은 원본 카드가 다시 뽑히거나 소멸되어도 유지됩니다.
- 사용 시 지연 예약을 만든 지속 카드는 마지막 예약이 발동할 때까지 유지됩니다. 마지막 발동 직전에 해당 사용 건의 유지 효과를 해제하고 원래 꿈/악몽 **버림 더미**로 반환합니다. 지연 효과 자체는 일반 일회 효과로 실행하므로 하위 상태이상은 자신의 Turns 동안 유지됩니다.
- 이 지연 지속 카드에는 기존 Continuous Turns 또는 Until Battle End 대신 마지막 예약 완료 시점을 수명으로 사용합니다. Exhaust On Use가 설정되어 있으면 영구 지속 카드라도 사용 시 소멸하고 반환하지 않습니다.
- 지연이 없는 기존 지속 카드의 기간제 만료·뽑을 더미 복귀와 영구 흡수 규칙은 유지합니다. 탄약 조건을 통과하지 못해 지연 예약이 실제로 등록되지 않으면 기존 수명 규칙을 따릅니다.
- `turnStartEffects` 안의 DelayEffect는 매번 별도 예약을 만듭니다. 그 예약은 원본 지속 카드의 수명을 연장하거나 종료시키지 않습니다.

## 상태창과 설명

예약마다 상태창에 아이콘과 남은 턴을 표시합니다. 마우스를 올리면 카드 이름, **N턴 뒤 발동**, 해당 지연 효과의 설명을 확인할 수 있습니다. 발동·전투 종료 시 해당 아이콘과 열린 툴팁이 정리됩니다. 유지 효과가 없는 지연 지속 카드는 예약 아이콘만 사용합니다.

Description은 **자신의 Effects 목록**을 기준으로 기존 토큰을 사용합니다.

```text
적에게 기본 피해 {damage:0}를 주고 방어도 {block:1}을 얻습니다.
```

이 예시는 Effects[0]이 DamageEffect, Effects[1]이 BlockEffect일 때 사용합니다. 조건부 하위 효과는 `{damage:0.0}`, 탄약 조건은 `{ammoCost:0}`와 `{ammoCondition:0}`을 사용합니다. 예약 툴팁의 수치는 기본값이며 미래 상태를 확정한 값이 아닙니다. 상태창 설명 계산은 실제 효과 실행·탄약 소비·상태 변경을 하지 않습니다.

기존 카드 Description에서 지연 내부 효과를 참조할 때는 지연 효과의 인덱스를 포함합니다. 예를 들어 Effects[1]이 DelayEffect이고 그 첫 하위 효과가 피해라면 `{damage:1.0}`입니다. 지연 하위 상태·장전은 같은 카드의 뒤쪽 즉시 효과 미리보기에 영향을 주지 않습니다.

## 전투 종료

캐릭터 사망 시 `BattleManager`는 `FinishBattle()`에 승리 또는 패배 결과를 전달합니다. 인자 없는 `EndBattle()`은 전투 중단으로 처리합니다. 전투 종료, `BattleManager` 비활성화, 새 전투 초기화에서는 대기 예약을 모두 취소합니다. 취소는 지연 효과를 발동하거나 흡수 카드를 반환하지 않습니다. 효과 처리 중 사망하면 남은 효과와 후속 예약도 중단합니다.

전투 결과에 따른 화면과 런 진행은 [전투 보상](BattleRewards.md)과 [군인 패배 연출](CharacterPresentation.md#군인-패배-연출)에 있습니다.
