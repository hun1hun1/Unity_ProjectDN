# 카드 연출

카드의 `presentation`은 선택 사항입니다. 비어 있으면 기존 효과 처리만 실행합니다. 연출은 게임 효과를 실행하거나 피해량을 바꾸지 않습니다.

## 구성

`CardPresentation`에 `beforeImpact`와 `afterImpact` 단계 목록을 지정합니다. 손패의 카드는 먼저 `CardUsingArea`로 이동한 뒤 앞 연출, 기존 카드 효과, 뒤 연출 순으로 실행합니다. 이 과정에서는 사용 영역에 머물며, 뒤 연출까지 끝난 후 버림·소멸·지속 카드 흡수 애니메이션을 실행합니다. X 코스트의 효과 반복 횟수는 유지하며, 연출은 카드 사용당 한 번 실행합니다. 지속 카드의 등록/즉시 효과는 같은 경계에서 실행하고, 이후 턴의 효과에는 사용 연출을 반복하지 않습니다.

각 단계는 공유 설정 에셋이고 실행 상태는 `CardPresentationContext`가 보관합니다. 이동 대상은 플레이어/적 중 선택합니다. 누락된 Visual은 건너뛰므로 게임 효과는 계속 동작할 수 있습니다.

## 단계

- `MoveVisualPresentationStep`: 기준 위치에 상대적인 이동과 Z 회전. `relativeToSize`이면 오프셋은 표시 크기의 비율입니다. `(0, 0)`과 회전 0으로 복귀합니다.
- `WaitPresentationStep`: 지정한 시간만큼 대기합니다.
- `PlaySpritePresentationStep`: `UISpriteAnimation`을 한 번 재생하며 완료를 기다릴 수 있습니다. 연출 종료 시 이전 재생 상태를 복원합니다.
- `SpawnVfxPresentationStep`: 선택한 Visual 아래에 효과 프리팹을 생성합니다. 장식용 효과이며 피해 판정은 포함하지 않습니다.
- `ProjectilePresentationStep`: 플레이어/적의 Visual 사이를 이동하는 효과입니다. 도착 후 원래 카드 효과가 실행되도록 앞 연출에 배치할 수 있습니다.
- `PlaySoundPresentationStep`: 공간감 없는 효과음을 재생합니다. 완료를 기다리지 않으면 나머지 연출과 겹쳐 재생되고, 연출 정리 시 종료합니다.

## 에셋 설정

Project 창의 Create > Card > Presentation 메뉴에서 정의와 단계 에셋을 만들고 카드의 Presentation 필드에 연결합니다. 공통 단계를 여러 연출에서 재사용할 수 있습니다. 기본 근접 연출은 `Assets/CardPresentations/Melee.asset`에 제공하며, 각 카드에 명시적으로 연결해야 합니다. 기존 카드는 자동으로 근접 카드로 분류하지 않습니다.

예제는 `ProjectDN/Setup Card Presentation Examples`로 생성합니다. 기존 `GeneratedArt/Soldier/Fire-v2`의 시트를 Sprite로 가져와 사격 연출을 만듭니다. 군인 시작 덱의 꿈 기본 공격 카드에 연출이 비어 있을 때만 사격 예제를 연결합니다. 이미 지정한 연출이나 예제 설정은 덮어쓰지 않으며, 씬·프리팹을 교체하지 않습니다.

## 실행과 정리

기존 `BattleManager`의 카드 효과 코루틴이 실제 효과를 담당합니다. 연출 단계는 효과를 직접 호출하지 않습니다. 연출이 끝나거나 중단되면 위치/회전과 스프라이트 재생 상태를 복원하고 임시 효과/소리를 정리합니다. 캐릭터 레이아웃 변경에는 기준 위치와 일시적인 연출 오프셋을 합성합니다. 체력 UI와 상태 UI는 이동하지 않습니다.

계획 중인 체력 변화 숫자는 앞 연출 뒤 실제 효과가 HP를 변경할 때 시작합니다. 지속·지연 효과로 HP가 바뀌는 경우에도 같은 표시를 사용하며, 뒤 연출과 후속 효과는 숫자가 떠오르는 동안 이어집니다. [체력 변화 숫자 연출 계획](CharacterPresentation.md#체력-변화-숫자-연출-계획)

기존 `UISpriteAnimator.SetAnimation`은 반복 재생을 유지합니다. `Play(animation, false)`는 한 번 재생 후 마지막 프레임에서 정지합니다.

## 적 행동 연출

`EnemyAction`의 `Presentation`에도 같은 연출 에셋을 지정할 수 있습니다. 실제 적 턴은 앞 연출 → 행동 효과 → 뒤 연출을 기다린 뒤 다음 행동 예고와 플레이어 턴으로 진행합니다. 복합 행동은 하위 행동에 지정한 연출도 순서대로 기다립니다. 연출이 비어 있으면 기존 행동 효과를 즉시 실행합니다. 직접 호출하는 `EnemyAction.Execute`는 연출 없는 게임 규칙 처리용이며, 연출을 포함하려면 `ExecuteRoutine` 또는 적의 턴 실행 경로를 사용합니다.

적 전용 근접 돌진 프리셋은 `Assets/CardPresentations/EnemyMelee.asset`입니다. 적용할 적 행동 에셋을 선택하고 `Presentation`에 연결합니다. 오른쪽의 적이 왼쪽을 바라보는 배치를 기준으로, 살짝 뒤로 준비 → 왼쪽으로 돌진 → 공격 효과 적용 → 잠깐 유지 → 원위치 복귀 순서입니다. 각 이동 단계의 대상은 `Enemy`이며 플레이어용 근접 단계와 별도 에셋으로 구성되어 있습니다.

연결 예제는 `Assets/Enemy/Examples/MeleeAttack.asset`에 있습니다. 기존 공격과 동일한 피해 10에 적 근접 연출을 지정한 독립 예제입니다. 사용하려면 적 행동 패턴의 원하는 항목에 이 에셋을 지정합니다. 기존 행동 패턴과 공격 에셋에는 자동으로 연출을 연결하지 않습니다.

적이 비활성화되거나 전투가 종료되면 남은 연출과 대기 중인 공격을 중단합니다. 실행 코루틴을 정리할 때 원래 위치·회전·스프라이트 상태를 복원하며, 같은 적의 턴을 중복 실행하지 않습니다. 체력 UI와 상태 UI는 이동하지 않습니다.
