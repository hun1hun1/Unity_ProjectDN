# X 코스트 카드

CardData의 **Cost Mode**를 **X**로 설정합니다. 카드의 꿈/악몽 종류에 맞는 현재 남은 코스트를 전부 소비하며, 이 모드에서는 기존 Dream Cost / Nightmare Cost 정수 값을 사용하지 않습니다. 기존 카드의 기본값은 Fixed입니다.

사용 시 소비한 코스트를 X로 고정하고, **Effects 목록 전체를 순서대로 X회 실행**합니다. 예를 들어 Effects가 [피해 5, 장전 1]이고 X=3이면 피해 → 장전 → 피해 → 장전 → 피해 → 장전 순서입니다. 효과로 코스트가 생겨도 이미 정한 반복 횟수는 늘어나지 않습니다. 카드 사용·코스트 지불·버림/소멸·손패 보충은 각각 한 번입니다.

## X=0

코스트가 0이어도 사용을 허용하며 Effects를 실행하지 않습니다. 카드 한 장은 정상적으로 버림 또는 소멸 처리하고 손패를 보충합니다. 지속 카드도 활성 기록을 만들거나 흡수하지 않으며, Exhaust On Use에 따라 버림/소멸 처리합니다.

카드 자체의 필수 탄약 조건과 소모 설정은 X와 별도로 기존 규칙을 따릅니다. 필수 탄약은 사용 시 한 번만 소모하며, Effects 안의 SpendAmmoBonusEffect는 반복할 때마다 해당 시점의 탄약을 검사하고 소모합니다. 코스트 지불 후 필수 탄약 지불이 실패하면 실제 지불했던 코스트를 환불합니다.

## 지속 카드와 입력 대기

X가 양수인 지속 카드는 한 개의 활성 사용 건을 만들고, 사용 시 Effects를 X회 적용합니다. 턴 시작 효과 목록과 지속 기간은 기존 규칙을 유지합니다. 턴마다 X회 반복하는 추가 규칙은 없습니다.

멀리건처럼 입력을 기다리는 효과는 완료 후 뒤의 효과와 다음 반복을 실행합니다. 실행 중에는 기존 효과 입력 잠금을 유지합니다. 전투가 끝나거나 실행 주체가 비활성화되면 나머지 반복을 중단합니다.

DelayEffect의 예약이나 발동 로직은 변경하지 않았습니다. 이번 X 코스트 카드 구성에서는 지연 효과와의 조합을 사용하지 않습니다.

## 표시와 설명

손패·덱 목록·상세창의 코스트에는 **X**를 표시합니다. 카드 Description에서 `{x}`를 사용하면 일반 전투 표시에서는 현재 남은 해당 코스트를 보여줍니다.

```text
적에게 {damage:0}의 피해를 {x}번 줍니다.
```

기존 `{damage:0}`·`{block:0}`은 한 번의 효과 수치입니다. 앞선 반복의 상태이상·탄약 변화에 따라 후속 효과의 실제 결과는 달라질 수 있습니다. 우클릭 상세창과 전투 컨텍스트가 없는 표시에서는 `{x}`를 **X**로 보여줍니다. 설명 계산은 실제 코스트나 탄약을 소비하지 않습니다.

전투 중 코스트가 바뀌면 사용 가능한 카드의 설명도 갱신합니다. 사용 중인 카드는 지불 직전 설명을 유지하므로, 코스트를 전부 지불한 뒤 사용 애니메이션에 X=0으로 바뀌어 보이지 않습니다.

## 검증

Unity 6000.0.77f1에서 전체 EditMode 테스트 272개 통과, 실패 0개. X 코스트 검증 14개와 실제 BattleScene의 버림·소멸·손패 보충·멀리건 반복 검증을 포함합니다. 결과 파일: `.utmp/x-cost-full-suite.xml`.
