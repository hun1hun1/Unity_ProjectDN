# 멀리건 효과

Project 창에서 **Create > Card > Effect > Mulligan**으로 효과 에셋을 만든 뒤 CardData의 Effects에 넣는다. 기존 카드에는 효과를 임의로 추가하지 않았다.

| Inspector 설정 | 의미 |
| --- | --- |
| Hand Scope: Dream / Nightmare / Both | 꿈 / 악몽 / 두 손패를 합친 후보 |
| Count Mode: All / Fixed | 후보 전체 / 지정한 장수 |
| Count | Fixed일 때 교체할 장수. 후보가 적으면 후보 수로 제한 |
| Selection Mode: Manual / Random | 직접 클릭 / 중복 없는 무작위 선택. All에서는 무시 |

Both + Fixed 2는 양쪽에서 각각 2장이 아니라 **꿈·악몽을 합쳐 총 2장**이다. 같은 CardData를 사용하는 카드도 손패의 서로 다른 한 장으로 구분한다. 무작위 선택은 후보 카드마다 같은 확률을 사용한다.

Manual + Fixed에서는 실제 손패를 왼쪽 클릭한다. 선택된 카드에는 초록색 테두리가 표시되고 다시 클릭하면 해제된다. 안내 바의 0/2가 선택에 따라 바뀌며 필요한 장수를 모두 선택한 경우에만 **완료** 버튼을 누를 수 있다. 필요한 수를 선택했더라도 완료 전에는 교체하거나 다음 효과를 실행하지 않는다. All/Random과 후보가 없는 경우에는 선택 UI를 열지 않는다.

사용자 지정 규칙에 따라 선택 카드는 원래 꿈·악몽 **버림 더미**로 이동하고, 각각 실제 교체한 장수만큼 같은 덱에서 다시 뽑는다. 드로우 더미가 비면 기존 규칙대로 버림 더미를 섞으므로 방금 교체한 카드가 다시 나올 수 있다. 멀리건 자체는 카드 사용이 아니므로 대상의 카드 효과나 소멸 특성을 발동하지 않는다. 소유 덱은 변하지 않는다.

사용 중인 카드와 이동 중인 카드는 후보에서 제외한다. 다른 사용/드로우가 진행 중이면 정리된 뒤 후보를 확정한다. 선택 중에는 다른 카드 사용·드래그·상세창·덱 창·턴 종료를 차단하며, 완료 후 뒤의 효과와 사용 카드에 대한 기존 보충 드로우를 계속 실행한다. 교체 드로우는 손패 전체 보충이 아니라 실제 교체 수만큼 수행한다.

기존 즉시 효과는 기존 Execute 결과를 동기적으로 유지한다. 입력 대기가 필요한 효과는 ExecuteRoutine, 지속 카드의 사용 시 활성화는 ActivateContinuousRoutine을 사용하며 BattleManager의 순차 실행 경로를 통해 완료를 기다린다. 조건부 탄약 효과와 지속 카드에도 같은 경로가 적용된다. 지속 카드의 턴 시작 효과는 기존 규칙대로 드로우 전에 실행되므로 그 시점의 손패가 대상이다.

선택 UI와 테두리는 기존 Canvas/TMP 폰트를 이용해 런타임에 생성한다. 기존 씬·프리팹·카드 데이터 참조는 추가 설정 없이 유지된다. 전투 컴포넌트를 비활성화하면 대기 중인 실행을 명시적으로 정리하여 선택 표시와 입력 잠금이 남지 않게 한다. 확정한 교체의 데이터 이동은 애니메이션 전에 완료한다.
