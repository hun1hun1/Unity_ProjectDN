# 지속 카드 설정

`CardData.type`을 `Continuous`로 설정한 뒤 다음 필드를 지정합니다.

| 필드 | 의미 |
|---|---|
| `continuousDurationType` | `UntilBattleEnd`: 영구 지속, `FixedTurns`: 기간제 지속 |
| `continuousTurns` | 기간제 카드의 지속 턴 수. 1 이상이어야 합니다. |
| `exhaustOnUse` | 기간제 카드 사용 시 소멸 여부. 영구 지속 카드는 항상 흡수됩니다. |
| `continuousIcon` | 상태창 아이콘. 지정하지 않으면 카드의 `artwork`를 사용합니다. |
| `turnStartEffects` | 다음 플레이어 턴 시작부터 매 턴 실행할 선택적 효과 목록. 사용한 턴에는 실행하지 않습니다. |

영구 지속 카드와 비소멸 기간제 카드는 사용 후 흡수되어 뽑을/버림 더미에서 제외됩니다. 비소멸 기간제 카드는 만료 시 원래 꿈/악몽 뽑을 더미의 무작위 위치로 돌아갑니다. 소멸 기간제 카드는 사용 즉시 전투 내 소멸 더미로 이동하고, 효과만 만료됩니다. 게임 중 보유 덱에서는 제거되지 않습니다.

`turnStartEffects`가 비어 있거나 유효한 효과가 없으면 이전처럼 양측 상태이상 감소 직후 남은 턴이 감소합니다. 현재 턴에 사용한 1턴 카드는 다음 플레이어 턴 시작에 만료됩니다.

매 턴 발동 효과가 있는 카드는 사용 시 반복 효과를 실행하지 않습니다. 다음 플레이어 턴부터 코스트·방어도를 초기화하고 매개체의 턴 시작 장전을 처리한 뒤 반복 효과를 실행하며, 남은 턴을 줄여 만료된 카드를 정리한 다음 드로우합니다. 그 단계의 모든 반복 효과가 끝나기 전에는 만료에 따른 유지 효과를 해제하지 않습니다. 턴 시작 처리 중에는 카드 사용·턴 종료 입력을 차단합니다.

예를 들어 3턴 반복 카드는 사용 시 0회, 다음 플레이어 턴 시작에 1회(남은 턴 2), 그다음 턴에 1회(남은 턴 1), 세 번째 턴에 마지막 1회를 발동하고 만료됩니다. 영구 카드도 다음 턴부터 매 턴 발동하지만 만료되지 않습니다. 만료 후 복귀한 카드는 그 턴 드로우에서 다시 뽑힐 수 있습니다.

## 효과 구성

`effects`와 `turnStartEffects`는 역할이 다릅니다. 각 목록 안에서는 지정된 순서대로 실행합니다.

- `ApplyStatusEffect`: 지속 카드에 포함되면 효과 자체의 `turns` 대신 카드의 수명을 따릅니다. 기존 일반 카드에서는 원래의 상태이상 지속 턴 합산 규칙을 유지합니다.
- `IncreaseMaxAmmoEffect`: 지속 카드가 활성화된 동안만 최대 탄약을 늘립니다. 만료 시 해당 사용 건의 보정만 해제하고 현재 탄약을 새 상한에 맞춥니다.
- 피해·회복·방어도·장전·코스트 등 즉시 효과: 사용 시 한 번 실행됩니다. 매 턴 반복되거나 만료 시 되돌아가는 효과가 아닙니다.

위 규칙은 기존 `effects` 목록에 적용됩니다. `turnStartEffects`에 넣은 효과는 매 턴 일반 `Execute()`로 실행됩니다. 예를 들어 `BlockEffect`는 매 턴 방어도를 얻고, `ApplyStatusEffect`는 매 턴 `turns`를 기준으로 상태를 새로 부여하며, `IncreaseMaxAmmoEffect`는 매 턴 전투 내 탄약 상한을 누적 증가시킵니다. 반복 실행으로 이미 얻은 회복·보정이나 부여된 상태는 각각의 기존 효과 규칙을 따릅니다. ‘활성 기간 동안 최대 탄약 +3 유지’처럼 만료 시 해제할 효과는 기존 `effects`에 넣습니다.

카드의 코스트와 필수 탄약은 사용 시에만 지불합니다. 다만 `turnStartEffects` 안의 `SpendAmmoBonusEffect`는 매번 자신의 탄약 조건을 검사하고 소비합니다.

군인의 응급 처치·응급 처치+와 보급로 개척은 `effects`의 `AddCostEffect`로 사용 즉시 악몽 코스트를 1 얻습니다. 이후 턴에는 `turnStartEffects`의 회복 또는 장전만 실행합니다. 보급로 개척+는 턴 시작 장전을 유지하며 악몽 코스트 획득 효과는 없습니다.

매 턴 방어도 5를 얻는 3턴 카드는 `continuousDurationType = FixedTurns`, `continuousTurns = 3`으로 설정하고 방어도 5의 `BlockEffect`를 `turnStartEffects`에 넣습니다. 이 방어도 효과를 기존 `effects`에도 넣으면 사용 시에도 별도로 한 번 실행됩니다.

## 설명 토큰과 상태 툴팁

기존 `{damage:0}`, `{block:0}`, `{ammoCost:0}`, `{ammoCondition:0}` 토큰은 `effects`를 참조합니다. 반복 효과 목록은 `{turnDamage:0}`, `{turnBlock:0}`, `{turnAmmoCost:0}`, `{turnAmmoCondition:0}`, `{turnStatusTurns:0}`을 사용합니다. 조건부 하위 효과는 `{turnDamage:0.0}`처럼 경로를 지정합니다. 매 턴 적에게 새로 부여하는 턴제 약점 노출은 약점 각인기의 보정을 받습니다. [턴제 상태 설명](CardDescriptions.md)

방어 파괴 상태에서는 실제 방어도 획득과 `{block:0}`·`{turnBlock:0}` 표시 수치가 모두 50%로 감소하며 소수점 이하는 버립니다. 이미 보유한 방어도는 감소시키지 않습니다. 우클릭 카드 확인 창에서는 기존대로 원래 수치를 표시합니다. 상태 정의는 `Assets/StatusData/DefenseBreak.asset`이며 기존 `ApplyStatusEffect`의 `status`에 연결해 사용합니다.

반복 효과의 설명은 현재 전투 상태를 기준으로 한 참고값이며, 다음 턴까지 발생할 상태·탄약 변화를 예측하지 않습니다. 사용 시 필수 탄약을 다시 차감하지 않는 독립된 복사본에서 계산합니다. 우클릭 카드 확인 창의 원래 수치 표시 규칙도 유지합니다. 상태 설명 툴팁은 두 효과 목록을 모두 확인합니다.

새로운 지속 효과는 `CardEffect.ActivateContinuous(BattleManager, ActiveContinuousCard)`를 재정의하여 적용하고, 해당 사용 건만 해제하는 `System.Action`을 반환합니다. 공유 `CardEffect` 에셋에 남은 턴이나 캐릭터 참조 같은 실행 상태를 저장하지 않습니다.

`BattleCharacter.ContinuousCards.ActiveCards`는 사용 건별 활성 기록입니다. 같은 카드 여러 장도 남은 턴과 복귀가 독립적입니다. 상태창에는 카드별 아이콘과 남은 턴을 표시하고, 영구 카드는 `∞`와 ‘전투 종료까지 지속’을 표시합니다. 기존 상태이상 아이콘도 함께 유지합니다.

전투 종료와 `BattleManager` 비활성화, 새 전투 초기화에서 활성 기록을 지우고 등록된 효과를 해제합니다. 정리 과정에서 이전 활성 카드를 뽑을 더미에 추가하지 않습니다.

## 공격·스킬 카드의 소멸

- CardData의 Card Traits > Exhaust On Use를 켜면 공격·스킬 카드도 사용 후 해당 꿈/악몽 소멸 더미로 이동한다. 버림 더미 재순환에 포함되지 않으며 보유 덱에서는 삭제되지 않는다.
- 기존 공격·스킬 카드의 설정은 변경하지 않았다. 영구 지속 카드는 이 설정과 관계없이 흡수되며, 일정 턴 지속 카드의 기존 소멸/복귀 규칙을 유지한다.
- 소멸 특성이 있는 카드는 상태이상 효과 유무에 관계없이 손패 호버 툴팁과 우클릭 상세 설명창에 소멸 설명이 자동 표시된다. 소멸은 캐릭터 상태이상으로 등록되지 않는다.
