# 타이틀 화면

`Assets/Scenes/TitleScene.unity`가 Build Settings의 첫 씬입니다. 전용 배경 이미지와 로고, 남청색 메뉴 버튼 이미지를 적용했으며 기본 네 버튼을 표시합니다. 유효한 진행 파일이 있으면 `이어서 하기`가 추가로 표시됩니다.

| 버튼 | 동작 |
|---|---|
| 이어서 하기 | 최근 체크포인트를 복원하고 전투·보상·비전투 노드 또는 맵을 재개합니다. |
| 게임 시작 | 같은 씬에서 캐릭터 선택 창을 엽니다. 군인을 선택하고 `모험 시작`을 확정하면 새 진행을 만들고 `MapScene`으로 이동합니다. |
| 튜토리얼 | 4쪽 설명창을 표시합니다. 이전·다음·닫기 버튼을 사용하며 게임 진행은 변경하지 않습니다. |
| 옵션 | 전투 화면과 같은 `SettingsPanel.prefab`과 설정 서비스를 사용합니다. 전체·배경음·효과음 음량, 해상도·전체 화면, 초기화, 종료 확인을 제공합니다. |
| 게임 종료 | 확인창의 종료 버튼을 눌렀을 때 설정을 저장하고 게임을 종료합니다. 취소 또는 ESC로 돌아옵니다. |

캐릭터 선택·튜토리얼·종료창은 ESC로 닫습니다. 옵션 창에서는 해상도 목록 → 종료 확인창 또는 옵션 창 순으로 앞에 열린 UI를 닫습니다. 창이 열려 있거나 닫히는 프레임에는 아래 메뉴가 실행되지 않습니다. 게임 시작 중에는 중복 시작을 막습니다.

저장 기준과 비전투 노드 연결 계약은 [RunCheckpoints.md](RunCheckpoints.md)에 있습니다.

## 외형과 선택 표시

이미지는 `Assets/Images/UI/Title/`에 있습니다. 메인 메뉴 다섯 버튼과 종료 확인창의 취소 버튼은 일반 남청색 이미지를, 종료 확정 버튼은 붉은 이미지를 사용합니다. 버튼은 Sprite Swap으로 기본·마우스 올림·누름·선택·비활성 이미지를 전환하며 기존 On Click 연결과 자식 TextMeshPro 문구를 유지합니다.

메인 메뉴 다섯 버튼의 Navigation은 None입니다. 타이틀 진입 시 자동 선택하지 않으며, 튜토리얼·종료 확인창·옵션 창을 닫으면 선택을 해제해 강조 표시가 남지 않도록 합니다. 메인 메뉴의 키보드 방향키 탐색은 제공하지 않습니다. 팝업 안의 선택과 ESC 닫기는 유지합니다.

현재 타이틀 메뉴는 버튼 이미지 전환으로 호버 상태를 표시합니다. 선택 마름모는 현재 구현 범위에서 제외했습니다. 이어서 하기가 숨겨져도 다른 메뉴 위치를 당기는 자동 레이아웃은 없습니다. 같은 씬에서 캐릭터 선택 패널을 열면 타이틀 위에서 0.2초에 걸쳐 페이드 인합니다. 전환 중에는 양쪽 버튼 입력을 차단하고, 패널이 완전히 나타나면 타이틀 메뉴를 숨기고 슬롯 입력을 엽니다.

## 마우스 포인터

타이틀·맵·전투에서 기본 포인터와 호버 포인터를 공유합니다. 둘 다 아이보리 화살촉과 남청색 윤곽이며, 호버 상태에서는 황동 장식이 밝아집니다. 활성 버튼이나 호버 가능한 카드 위에서 호버 포인터를 표시합니다. 적이나 비활성 버튼 위에서는 기본 포인터를 유지합니다.

[기본](../Assets/Resources/Cursors/Default.png)과 [호버](../Assets/Resources/Cursors/Hover.png)는 32×32 커서 텍스처이며 왼쪽 위 기준 (2, 2)의 클릭 지점을 공유합니다. [GameCursor](../Assets/Scripts/UI/GameCursor.cs)가 첫 씬 로드 전에 초기화되고 씬 사이에 유지됩니다. 창이 포커스를 잃으면 시스템 커서로 돌아갑니다.

2026-11-18 Unity 6000.0.85f2에서 커서 에셋과 클릭 지점, 활성 버튼 판정, 세 씬에서 포인터 인스턴스 유지, 타이틀·카드 호버를 포함한 관련 검사 21/21이 통과했습니다. 결과는 로컬 `.utmp/game-cursor-graphics.xml`에 있습니다. 실제 게임 창에서 커서의 표시 크기와 호버 전환을 육안으로 확인하는 작업은 남아 있습니다.

## 캐릭터 선택

`TitleScene`의 Canvas 아래에 [CharacterSelectionPanel.prefab](../Assets/Prefabs/UI/CharacterSelectionPanel.prefab)을 배치합니다. `게임 시작`으로 열거나 뒤로 돌아갔다가 다시 열 때는 선택이 비어 있습니다. 군인을 선택하면 전신과 소개, 고유 자원, 시작 매개체, 시작 덱이 표시됩니다. 선택을 해제하면 전신과 정보 영역을 숨기고, 덱 상세도 접습니다. 슬롯은 세 개이며 군인만 선택할 수 있고 나머지 두 슬롯은 자물쇠와 `준비 중`을 표시합니다.

군인 슬롯을 누르면 금색 테두리와 `선택됨` 표시가 나타나고 `모험 시작`이 활성화됩니다. 모험 시작을 확정하면 탄피를 가진 상태로 1층 13노드를 시작합니다. 군인 슬롯을 한 번 더 누르면 선택을 해제할 수 있습니다. `뒤로` 또는 ESC로 닫을 때에는 기존 진행과 저장 파일을 유지합니다. `이어서 하기`는 이 창을 건너뛰고 저장된 체크포인트를 복원합니다. [현재 실행 구성](MapSystem.md#현재-실행-구성)

`CharacterSelectionUI`가 선택 상태와 시작 덱 미리보기를 관리합니다. 꿈 8장과 악몽 6장은 각각 군인 시작 덱 DB를 읽어 표시하며, 상세를 펼치면 중복 카드를 이름과 수량으로 묶어 보여 줍니다. 씬의 `모험 시작` 버튼은 `TitleMenuUI.ConfirmAdventure`에 연결됩니다. 군인이 선택된 경우에 `RunSession.StartNewRun`으로 현재 `TemporaryRun`을 시작하고, 기존 진행 저장을 새 체크포인트로 교체합니다. 공용 남청색 안개로 타이틀을 덮고, 맵이 준비된 뒤 안개를 걷습니다. 전투 진입에도 같은 연출을 사용합니다. [공용 안개 전환](MapSystem.md#노드-진입-연출과-씬-전환) 참고. 캐릭터별 런 설정과 선택 캐릭터 식별자 저장은 다중 캐릭터 지원 범위입니다.

### 배치와 리소스

- 기존 타이틀 배경을 어둡게 재사용합니다. 좌상단에는 금색 Hahmlet SemiBold 영문 브랜드와 흰색 Noto Sans KR Bold 한글 제목을 왼쪽 정렬합니다.
- 왼쪽에는 테두리 없이 군인 전신과 이름을 배치합니다. 전신 스프라이트를 오른쪽으로 옮겨 이름을 몸통 아래에 맞췄습니다. 오른쪽 남청색 패널은 소개, 탄약, 시작 매개체, 시작 덱의 순서로 배치합니다. 탄피 행은 탄약 바로 아래에 두고, 왼쪽에 64×64 아이콘, 오른쪽에 이름과 효과 설명을 표시합니다. 미리보기는 실제 군인 새 런에 지급하는 시작 매개체 에셋에서 읽습니다.
- 하단 슬롯은 1920×1080 기준 260×110, 간격 20으로 중앙 배치합니다. 왼쪽 전용 칸에는 기존 철모 심볼이나 자물쇠를 두고, 오른쪽에는 이름과 상태 문구를 둡니다. 군인 슬롯은 선택 전에 은색 테두리를 쓰고 선택하면 금색으로 바뀝니다.
- 하단의 `뒤로`와 `모험 시작`은 각각 은색 테두리의 남청색 버튼과 금색 테두리의 청동색 버튼입니다. 패널·버튼·슬롯 이미지는 [CharacterSelection 리소스](../Assets/Images/UI/CharacterSelection)에 있습니다.

## Inspector에서 내용 변경

- **버튼 위치·크기·문구:** `TitleScene`의 `Canvas/TitleMenu/MainMenu` 아래 각 버튼과 `Text`를 수정합니다.
- **튜토리얼 문구:** `Canvas/TitleMenu`의 `TitleMenuUI` 컴포넌트에서 `Tutorial Pages` 배열의 각 `Title`, `Body`를 수정합니다.
- **캐릭터 선택 외형과 미리보기**는 `CharacterSelectionPanel.prefab`의 레이아웃과 `CharacterSelectionUI`의 꿈·악몽 DB 참조를 수정합니다. `뒤로`와 `모험 시작`의 타이틀 호출은 씬 인스턴스에서 관리합니다.
- **새 게임 데이터**는 `TitleMenuUI.Run Definition`에 연결합니다. 현재 `MapScene`과 같은 `TemporaryRun`을 참조하며 시작 골드는 100입니다.
- **공용 옵션 UI:** `Assets/Prefabs/UI/SettingsPanel.prefab`을 수정합니다. 타이틀 씬 인스턴스는 전체 화면 크기로 배치합니다. `Canvas/Settings`의 `Require Battle`과 `Return To Title`은 꺼져 있어 전투 없이 열고 프로그램 종료 확인을 제공합니다. 전투 씬에서는 두 항목을 켜고 타이틀 복귀를 처리합니다.

`ProjectDN/Setup Title Scene`은 씬이 없을 때만 생성하며, 이미 만들어진 타이틀 씬의 수동 편집 내용을 덮어쓰지 않습니다.

Unity Editor에서는 `Application.Quit()`가 에디터를 닫지 않고 해상도 적용도 실제 창에 반영하지 않습니다. 실제 프로그램 종료와 창 크기 전환은 빌드에서 동작합니다.

## 검증

2026-11-11 Unity 6000.0.85f2에서 캐릭터 선택 페이드와 전환 중 양쪽 입력 차단을 포함한 타이틀·캐릭터 선택·맵·저장 관련 검사 20/20이 통과했습니다. 로컬 결과는 `.utmp/title-fade-final.xml`입니다.

2026-11-11 Unity 6000.0.85f2에서 타이틀 메뉴 검사 6/6과 모험 시작·전투 진입이 공용 안개 화면을 사용하는 씬 검사를 확인했습니다. 로컬 결과는 `.utmp/scene-fog-20261111/title.xml`과 `final.xml`입니다.

2026-11-04 Unity 6000.0.77f1에서 캐릭터 선택 전후 화면을 확인했습니다. 캐릭터 선택·타이틀 메뉴 관련 7건이 통과했습니다. 선택 전 모험 시작 차단, 군인 선택 후 활성화, 뒤로·ESC, 다시 열 때 선택 초기화, 저장 교체와 맵 이동을 확인했습니다.

같은 실행에서 체크포인트 테스트 9건 중 8건이 통과했습니다. 카드 보상 복원 테스트 한 건은 첫 실행에서 실패하고 단독 재실행에서 통과했습니다. 실행 결과는 로컬 `.utmp/character-selection/`의 `explicit-selection-final.xml`과 `explicit-selection-checkpoint-retry.xml`에 있습니다. 이 결과의 범위는 관련 테스트와 Editor 화면 확인입니다.

전신과 설명의 표시를 선택 상태에 연결한 뒤 타이틀 메뉴 테스트 6건을 다시 실행해 모두 통과했습니다. 선택 전 숨김, 선택 후 표시, 선택 해제 및 덱 상세 초기화를 확인했습니다. 결과는 로컬 `.utmp/character-selection/selected-only-final.xml`에 있습니다.
