# 상태이상 구현 계획

**목표:** 카드로 약점 노출(받는 피해 +50%)과 녹슬음(주는 피해 -25%)을 적용하고 아이콘·남은 턴 및 적 행동 예고를 동기화합니다.

**구조:** 공유 StatusEffectData에는 정의만 저장하고, BattleCharacter마다 StatusEffectSystem이 지속 턴을 보유합니다. CardData → CardEffect와 EnemyBehavior → EnemyAction 구조를 유지합니다. 공통 DamageCalculator를 실제 공격과 예고에 사용하며 방어도 차감 전에 두 배율을 합산 적용하고 최종 소수점만 버립니다.

**사용자 확정 규칙(추가 요청 반영):** 플레이어 턴 시작 시 가장 먼저 양쪽 캐릭터의 남은 턴을 1 감소합니다. 동일 상태 재적용은 남은 턴 추가, 비율 중첩 없음. 플레이어 턴에 적용한 1턴 상태이상은 이번 적 행동까지 유지하고 다음 플레이어 턴 시작에 해제합니다.

**구현 순서:**

- [x] 테스트를 먼저 작성하여 미구현을 확인합니다.
- [x] 상태 정의/개별 지속 상태, 피해 계산, 카드 상태 적용 효과를 구현합니다. 음수 피해 및 턴, 잘못된 정의, 정수 오버플로를 방어합니다.
- [x] 플레이어 턴 시작의 양쪽 지속 턴 감소와 전투 시작 초기화를 연결합니다. 두 캐릭터 상태 변경에 적 행동 UI가 반응하고 공유 EnemyAction은 변경하지 않습니다.
- [x] CharacterInfoUI의 기존 StatusContainer에 상태 UI를 연결합니다. 기본 아이콘 프리팹의 오른쪽 아래에 턴 수를 배치하고 재적용/만료/재활성화를 반영합니다.
- [x] 플레이어/적에게 적용하는 상태 카드 예시를 생성합니다. 기존 시작 덱과 보상 풀은 변경하지 않습니다.
- [x] Unity 6000.0.77f1에서 기존·새 테스트와 실제 전투를 검증하고 직렬화 참조 및 인코딩을 확인합니다.

**검증 결과:** Unity 6000.0.77f1 테스트 89개 통과(기존 61개 + 신규 28개), 실패 0개. 실제 BattleScene 카드 적용과 턴 종료 피해·예고·아이콘을 검증했습니다. 에셋 GUID, 기존 시작 덱, 소스 인코딩을 확인하고 자동 생성된 폰트 변경을 작업 시작 전 내용으로 복구했습니다. 읽기 전용 코드 리뷰에서도 수정이 필요한 결함은 발견되지 않았습니다.

**턴 시작 감소 변경 검증:** Unity 6000.0.77f1 전체 테스트 90개 통과, 실패 0개. 1턴 상태이상이 이번 적 공격까지 유지되고 다음 플레이어 턴 시작에 해제되며, 양쪽 감소가 턴 상태 전환·방어도 초기화·카드 드로우에 앞서는 것을 실제 전투 테스트로 확인했습니다.
