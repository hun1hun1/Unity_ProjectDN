# Mulligan Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan inline. The user explicitly requested implementation of the discussed design and click UI.

**Goal:** 손패 전체/직접/무작위 멀리건과 초록색 테두리, 선택 수, 완료 버튼을 구현한다.

**Architecture:** MulliganEffect 설정과 MulliganSystem 선택·교체를 분리한다. EffectSequence가 IEnumerator를 펼쳐 기존 즉시 효과의 동기 결과를 유지하며 선택 완료를 기다린다. 기존 Canvas 안에 선택 바와 카드 테두리를 런타임 생성한다.

**Tech Stack:** Unity 6000.0.77f1, C#, uGUI, TMP, Unity Test Framework.

**Spec:** docs/superpowers/specs/2026-10-16-mulligan-design.md

## Global Constraints

- 버림 더미 복귀를 사용한다. 꿈·악몽 각각 실제 교체 수만큼 뽑고 재셔플을 허용한다.
- 기존 카드, 씬, 프리팹 및 사용자 미커밋 변경을 보존한다. 소스 인코딩/개행과 메타 GUID를 유지한다.
- 기존 즉시 효과/지속 효과/소멸/턴 시작 순서를 보존하고 선택 중 효과와 턴 전환을 차단한다.
- 커밋/브랜치 변경은 요청 범위에 포함되지 않으므로 수행하지 않는다.

## Review Focus

- 같은 CardData 여러 장과 꿈·악몽 합계 선택에서 카드 한 장 및 원래 덱을 구분한다.
- 다른 사용/드로우가 진행 중일 때 선택 후보와 보충 드로우가 변경되지 않도록 대기한다.
- 수동 선택 중 다음 효과/탄약 추가 효과/지속 만료가 먼저 실행되지 않도록 순서를 보존한다.
- 선택 수 부족·과다·후보 없음·비활성화에서도 UI/잠금이 남지 않는다.
- 코루틴 도입 후 기존 즉시 결과와 전투 상태·코스트·소멸 동작을 유지한다.
