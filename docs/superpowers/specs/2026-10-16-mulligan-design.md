# 멀리건 효과 설계

사용자가 승인한 앞선 효과 설계와 클릭 선택 요구를 구현한다. 범위는 꿈/악몽/양쪽 합계, 개수는 전체/지정 개수, 지정 방법은 직접/무작위다. 직접 선택은 실제 손패 카드를 클릭하여 초록색 테두리로 표시하며 재클릭하면 해제한다. 선택 수는 0/2 형태로 표시하고 필요한 수를 선택한 경우에만 완료 버튼으로 확정한다. 전체와 무작위는 확인 UI 없이 진행한다.

사용자 확정: 교체 카드는 **버림 더미로 이동**한다. 각 덱에서 실제 교체한 장수만큼 다시 뽑으며, 버림 더미를 다시 섞으면 교체 카드도 다시 나올 수 있다. 후보가 부족하면 후보 수로 제한하고, 후보가 없으면 즉시 종료한다. 사용 중인 카드 및 이동 중인 카드를 제외하며 카드 한 장은 CardUI 인스턴스로 구분한다. 멀리건은 카드 사용이 아니므로 대상 효과나 소멸 특성을 발동하지 않는다.

CardData/CardEffect 구조와 기존 효과의 즉시 실행 결과를 보존한다. IEnumerator 실행 경로를 기본 어댑터로 추가하고 중첩 효과, 지속 효과 활성화, 턴 시작 효과도 같은 순차 실행을 사용한다. 기존 동기 호출은 즉시 완료 가능한 루틴을 동기 처리하는 펌프로 호환한다. 선택 중 다른 카드 사용/드래그/상세창/덱 창/턴 종료를 막는다. 먼저 진행 중인 다른 사용/드로우를 정리한 뒤 후보를 고정하고, 완료 후 카드 효과를 이어 실행한다. 기존 사용 카드의 보충 드로우는 마지막 한 번만 유지한다.

선택 UI는 기존 Canvas와 TMP 폰트를 사용하여 필요할 때 런타임에 생성한다. 실제 손패의 시각 영역에 클릭을 가로채지 않는 초록색 테두리를 표시한다. 기존 씬, 프리팹, 카드 에셋은 바꾸지 않는다. 중단/비활성화 시 선택 UI, 테두리, 입력 잠금을 정리하고, 교체 확정 이후 데이터 이동은 원자적으로 처리한다.

Unity 6000.0.77f1과 기존 패키지만 사용한다. 기존 CP949/UTF-8 및 개행, GUID를 보존하고 사용자 카드 이동 및 기존 미커밋 변경을 유지한다. 새 효과는 CreateAssetMenu로 생성 가능하게 제공하며 기존 카드에 임의로 부착하지 않는다.
