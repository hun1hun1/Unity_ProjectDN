# Soldier 총알 설계

- 기존 `CardData` / `CardEffect`와 `Player` 참조를 유지합니다.
- Soldier는 Player를 상속하고 별도 AmmoSystem을 사용합니다. 최대 10알, 시작 0알이며 Inspector에서 변경합니다.
- BattleScene의 기본 플레이어와 시작 덱은 유지합니다. Soldier는 별도 프리팹으로 제공합니다.
- 장전은 최대치까지 채우며, 최대치에서는 장전 부분만 무효입니다.
- 추가 효과는 필요한 총알을 한 번에 소모할 수 있으면 반드시 실행합니다. 부족하면 기본 효과만 실행하며 부분 소모하지 않습니다.
- CardData의 필요 총알 수와 소모 여부로 보유 조건만 검사하는 카드와 필수 소모 카드를 모두 표현합니다. 기존 카드는 필요량 0으로 동작합니다.
- 사용 조건은 카드 효과 전에 검사하고, 모든 자원 부족 판정은 어떤 자원도 지불하기 전에 완료합니다.
- 총알 소모는 카드 코스트 지불이 성공한 사용에서만 실행합니다. 필수 소모는 기본 효과 전에, 추가 소모는 해당 효과 순서에서 수행합니다.
- 총알 상태는 캐릭터 인스턴스에 저장하며 카드/효과 에셋에는 설정만 저장합니다. 턴이 바뀌어도 자동으로 초기화하지 않습니다.
- 총알 기능이 없는 기본 Player는 필요량이 양수인 카드를 사용할 수 없습니다. 장전은 무효, 선택적 추가 효과는 생략됩니다.
- 동일 카드의 재사용을 차단하고, 사용 연출과 턴 종료의 중복으로 손패 보충이 잘못 진행되지 않도록 합니다.
- Unity 6000.0.77f1에서 경계값, 자원 미소모, 효과 묶음, 기존 카드 호환성, 프리팹 참조를 검증합니다.
