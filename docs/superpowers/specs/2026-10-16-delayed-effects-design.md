# 턴 지연 카드 효과 설계

## 목적과 확정된 요구

카드를 사용한 뒤 N턴이 지나면 지정한 효과를 정확히 한 번 실행한다. 주 사용처는 공격·스킬 카드이며 지속 카드에도 적용한다. 동일한 CardData를 사용하는 카드 여러 장도 사용 건별로 독립적으로 예약한다. 소멸 카드의 예약도 정상 발동하며, 전투 종료 후에는 모든 예약과 표시가 사라진다. 기존 지속 카드 상태창을 확장하여 각 예약의 남은 턴과 발동할 효과를 툴팁으로 보여준다.

앞선 대화에서 제안한 CardEffect 래퍼와 전투별 예약 관리 방식을 사용한다. 지속 카드 수명에만 지연을 추가하는 방식은 공격·스킬에 적용하기 어렵고, 카드 사용 코루틴을 여러 턴 대기시키는 방식은 기존 입력 잠금과 충돌하므로 사용하지 않는다.

## 턴과 실행 순서

- 사용한 턴은 계산하지 않는다. 플레이어 턴 시작을 N번 맞이했을 때 발동한다. N은 1 이상이다.
- 전투가 소유하는 턴 번호와 예약의 발동 예정 턴을 비교한다. 시작 손패를 나누는 시점에는 턴을 증가시키지 않는다.
- 플레이어 턴 시작 순서는 턴 번호 증가 → 기존 상태이상 감소 → 코스트·방어도 초기화 → 기존 지속 카드 턴 시작 효과 → 지연 효과 → 드로우 순서다.
- 같은 시점에 발동하는 예약은 등록 순서대로 실행한다. 처리할 예약 목록은 해당 지연 처리 단계 시작 시 고정한다. 실행 중 새 예약이 생겨도 같은 단계에서 재실행하지 않는다.
- 실행할 예약을 먼저 대기 목록에서 제거하고 기존 ExecuteEffectsRoutine으로 하위 효과의 완료를 기다린다. 멀리건과 같은 선택 효과도 완료 후 다음 예약으로 넘어간다. 턴 시작 처리가 끝나기 전에는 기존 입력 잠금을 유지한다.
- 카드 코스트와 필수 탄약은 사용 시 한 번 지불한다. 하위 효과 자체의 탄약 조건은 실제 발동할 때 평가한다. 피해·방어도·상태이상 역시 발동 당시 전투 상태를 사용한다.

## 구성과 상태 소유권

- DelayEffect : CardEffect에 delayTurns와 하위 CardEffect 배열을 둔다. CreateAssetMenu로 생성하여 기존 카드의 effects에 넣는다. Execute는 예약 등록 후 즉시 완료한다.
- PendingDelayedEffect는 예약 ID, 원본 카드, 발동 예정 턴, 하위 효과 배열의 복사본, 표시용 설명과 선택적인 지속 카드 사용 건을 보유한다. 효과 에셋 자체를 변경하거나 남은 턴을 저장하지 않는다.
- DelayedEffectSystem은 전투 인스턴스에 귀속된다. 대기 목록 읽기 전용 뷰, 변경 알림, 예약 등록·턴 진행·초기화 API를 제공한다.
- 원본 카드 정보는 효과 실행 컨텍스트로 전달한다. 조건부 탄약 보너스처럼 중첩된 기존 효과를 거쳐도 원본 카드와 사용 건을 잃지 않아야 한다.
- 턴 시작 반복 효과 안에 DelayEffect가 들어 있으면 그 반복 효과가 실행될 때마다 독립적인 일회 예약을 등록한다. 이미 등록된 예약을 반복 실행하지 않는다.
- 1 미만인 지연 수, 비어 있는 효과 목록, 잘못된 중첩 참조를 방어한다. 데이터 순환으로 설명 수집이나 미리보기가 무한 재귀하지 않게 기존 방문 집합 규칙을 유지한다.

## 카드 위치와 지속 카드

- 공격·스킬은 기존 사용 완료 절차를 따른다. 일반 카드는 버림 더미, 소멸 카드는 소멸 더미로 이동한다. 이후 원본 카드의 위치나 재사용 여부와 관계없이 등록된 예약은 유지된다.
- 지속 카드의 사용 시 effects에 DelayEffect가 있으면 예약이 발동할 때까지 해당 사용 건을 유지하고, 지연 효과 발동에 맞추어 지속 상태를 해제한다. 비소멸 사용 건은 원래 꿈/악몽 버림 더미로 이동시킨다. 기존 일반 지속 카드의 만료 시 뽑을 더미 복귀 규칙은 유지한다.
- 한 지속 카드 사용 건이 여러 사용 시 지연 예약을 만들면 각 예약은 제시간에 발동하며, 그 사용 건의 마지막 예약이 발동할 때 한 번만 해제·반환한다. 그보다 먼저 카드가 중복 반환되거나 뽑히지 않아야 한다.
- 지속 카드에 지연 예약이 있는 경우 위 예약 종료 시점이 해당 사용 건의 종료 기준이다. 기존 continuousTurns 또는 UntilBattleEnd가 먼저 종료시키지 않는다. 사용 시 지연 예약이 없는 지속 카드는 기존 수명 규칙을 따른다.
- 지연 지속 카드의 하위 효과는 일반 일회 효과로 실행한다. 상태이상은 하위 ApplyStatusEffect 자신의 turns를 사용하며 원본 지속 카드가 종료되었다는 이유로 즉시 해제되지 않는다.
- 지연 지속 카드의 소멸은 발동 시에도 유지되어야 한다. 영구 지속 카드의 기존 ‘항상 흡수’ 예외와 충돌하므로, 지연 종료를 사용하는 지속 카드에 한해 exhaustOnUse를 소멸 판정에 반영한다. 소멸 더미에 같은 사용 건을 중복 추가하지 않는다.
- 턴 시작 반복 목록에서 새로 만들어진 예약은 일회 예약으로 독립 유지하되, 원본 지속 카드 수명을 연장하거나 종료시키지 않는다.

## 상태창과 설명

- 기존 StatusEffectsUI, StatusIconUI, StatusTooltipUI를 확장한다. 기존 상태이상·지속 카드 바인딩은 호환한다.
- 예약 한 건마다 독립적인 아이콘을 플레이어 상태창에 표시한다. 카드 그림을 기본 아이콘으로 사용하고 DelayEffect에서 표시 아이콘을 선택적으로 지정할 수 있다.
- 아이콘에 남은 턴을 표시하고 툴팁은 카드 이름, ‘N턴 뒤 발동’, 발동할 하위 효과 설명을 보여준다. 같은 카드 여러 장 또는 여러 예약을 하나로 합치지 않는다.
- DelayEffect에는 지연 부분만 설명할 수 있는 전용 설명 필드를 제공한다. 피해·방어도 등은 하위 효과 목록을 대상으로 기존 설명 토큰 규칙을 재사용한다. 설명을 비운 경우에도 알려진 기본 효과에 대한 요약을 제공하여 빈 툴팁을 방지한다.
- 미래의 피해량은 확정하지 않는다. 기본 수치를 표시하고 실제 수치는 발동 당시 상태를 따른다고 알린다. 설명 생성은 실제 효과·탄약 소비를 실행하지 않는다.
- 하위 효과의 상태이상 설명도 기존 카드 호버와 상세창의 상태 수집에 포함한다. 지연 하위 효과의 상태나 장전은 즉시 실행 효과의 미리보기 상태에 반영하지 않는다.
- 남은 턴 변경 시 열린 툴팁을 갱신한다. 발동·전투 종료·바인딩 변경·컴포넌트 비활성화 시 해당 툴팁을 닫고 오래된 아이콘을 정리한다.
- 지연 지속 카드의 중복 표시는 피한다. 대기 중 지연 효과 설명은 예약 아이콘이 담당하며 기존 지속 효과는 필요할 때 기존 아이콘으로 표시한다.

## 전투 종료와 중단

- BattleManager에 전투 종료 진입 경로를 마련하여 BattleEnd 전환과 함께 예약을 전부 취소한다. 상태창 아이콘과 열린 툴팁도 정리한다.
- 플레이어 또는 적 HP가 0이 되는 경로에서 최소한 이 종료 경로를 호출하도록 연결한다. 보상·승리 화면·다음 전투 이동은 이번 범위에 포함하지 않는다.
- 효과 실행 도중 사망하거나 전투가 종료되면 현재 효과 목록의 나머지와 후속 예약을 실행하지 않는다. 적 공격으로 플레이어가 사망한 뒤 StartPlayerTurn으로 상태가 덮어써지지 않게 한다.
- 새 전투 초기화, BattleManager 비활성화·파괴 시에도 예약을 정리한다. 취소 시에는 지연 효과나 카드 반환을 실행하지 않는다.
- 기존 선택 효과 대기와 코루틴 정리는 기존 EffectSequence/MulliganSystem 정리 경로와 함께 처리하여 입력 잠금이나 떠 있는 카드 UI가 남지 않게 한다.

## 변경 범위와 검증

지연 효과 정의·예약 관리, BattleManager 효과 컨텍스트와 턴/종료 연결, 지속 카드의 지연 종료, 기존 상태창과 설명 수집, 관련 테스트와 사용 문서에 한정한다. 기존 카드에 효과를 임의로 추가하지 않으며 밸런스·보상 데이터베이스는 변경하지 않는다. 기존 인코딩·개행과 GUID를 보존하고 새 Unity 소스에는 .meta를 함께 둔다.

Unity 6000.0.77f1에서 다음을 검증한다.

1. N=1과 N>1이 정확한 플레이어 턴 시작에 한 번 실행되며 사용 즉시 실행되지 않는다.
2. 같은 카드의 중복 사용, 서로 다른 지연 값, 같은 시점의 여러 예약을 독립적으로 처리한다.
3. 지연 효과에서 새 예약이 생기거나 턴 시작 반복 효과에서 예약해도 조기 발동하지 않는다.
4. 공격·스킬의 버림·소멸과 기존 손패 보충, 지연 지속 카드의 버림 반환·소멸 및 마지막 예약 종료가 맞다.
5. 발동 시점 상태이상·탄약 조건과 중첩 효과·멀리건의 순서를 지킨다.
6. 아이콘·남은 턴·지연 부분 설명·열린 툴팁 갱신 및 발동/취소/재바인딩 정리가 맞다.
7. 전투 종료·사망·비활성화·재시작 뒤 예약이 남거나 실행되지 않는다.
8. 기존 지속 카드·소멸·멀리건·설명·상태 UI 테스트가 계속 통과한다.

이번 설계서는 코드 구현 전 검토 단계의 산출물이다. 구현과 Unity 검증 결과는 아직 없다.
