# 상태이상 카드와 표시 UI

카드의 `ApplyStatusEffect`와 적의 `EnemyApplyStatusAction`으로 상태이상을 부여할 수 있습니다. 상태 정의는 공유 에셋에 저장하고, 지속 턴과 중첩은 각 캐릭터가 별도로 관리합니다.

| 상태이상 | 효과 | 정의 에셋 |
| --- | --- | --- |
| 약점 노출 | 받는 피해 50% 증가 | `Assets/StatusData/WeaknessExposure.asset` |
| 녹슬음 | 주는 피해 25% 감소 | `Assets/StatusData/Rust.asset` |
| 방어 파괴 | 새로 얻는 방어도 50% 감소 | `Assets/StatusData/DefenseBreak.asset` |
| 화상 | 플레이어 턴 종료 시 중첩 수만큼 고정 피해, 이후 중첩 1 감소 | `Assets/StatusData/Burn.asset` |

## 버프와 디버프

`StatusEffectData.Category`는 상태를 `Buff` 또는 `Debuff`로 분류합니다. 기존 약점 노출·녹슬음·방어 파괴·화상은 디버프입니다. 버프의 종류는 `Status Effect Type`으로, 지속 규칙은 `Buff Duration`으로 정합니다. 카드와 적의 `Apply Status` 에셋에서 `Buff Power`를 설정하며, 턴제 버프는 `Turns`도 설정합니다.

| 지속 방식 | 적용 규칙 |
|---|---|
| `Fixed Turns` | 부여 즉시 적용하며, 플레이어 턴이 시작할 때마다 남은 턴을 1씩 줄입니다. |
| `Until Battle End` | 부여 즉시 적용하며, 전투가 끝나면 해제합니다. |
| `Next Turn` | 다음 플레이어 턴 시작에 발동해 그 턴과 이어지는 적 행동 동안 적용합니다. 이후 플레이어 턴 시작에 해제합니다. |
| `Next Attack` | 소유자가 다른 캐릭터에게 기본 피해가 양수인 공격을 한 번 하면 해당 공격 처리 후 소모됩니다. |
| `Next Incoming Attack` | 다른 캐릭터에게 기본 피해가 양수인 공격을 한 번 받으면 해당 공격 처리 후 소모됩니다. |

가시에 여러 수치가 부여되면 현재 발동 중인 수치를 합산합니다. 각 부여 건의 지속 시간과 소모 시점은 따로 관리합니다. HUD는 같은 종류를 아이콘 하나로 표시하고 툴팁에서 적용 중인 수치와 지속 조건을 보여 줍니다. 지속 카드가 부여한 버프도 상태 에셋의 지속 방식을 따릅니다.

### 가시

[가시](../Assets/StatusData/Thorns.asset)는 전투 종료까지 지속됩니다. 가시 보유자가 공격을 받고 살아남으면 공격자에게 가시 수치만큼 **고정 피해**를 줍니다. 방어도로 공격을 전부 막아도 발동하며, 반격 피해는 공격자의 방어도를 소모하지 않습니다. 자해와 공격자가 없는 피해에는 반응하지 않으며, 가시 반격끼리 연쇄하지 않습니다. 연속 공격은 살아남은 공격마다 반격하며, 반격으로 공격자가 쓰러지면 나머지 행동을 중단합니다.

카드에서 플레이어에게 가시를 부여하려면 [Thorns_PlayerEffect](../Assets/CardData/Status/Examples/Thorns_PlayerEffect.asset)를 연결합니다. 적이 자신에게 가시를 부여하려면 [BuffThorns](../Assets/Enemy/Examples/BuffThorns.asset)를 적의 행동 목록에 넣습니다. 두 예시의 기본 수치는 3입니다. 가시 덤불 매개체도 보유한 플레이어에게 전투 시작마다 가시 3을 부여합니다. [가시 덤불 설정](MapSystem.md#매개체-추가)

### 방호막

[방호막](../Assets/StatusData/Ward.asset)은 다음에 받는 공격 피해를 0으로 만든 뒤 소모됩니다. 기존 방어도는 보존합니다. 다시 부여해도 최대 한 번의 공격을 막으며, 연속 공격에서는 첫 타격에 소모됩니다. 자해·화상·가시의 고정 피해에는 소모되지 않습니다. 공격 피해를 막아도 가시와 공격에 딸린 별도 상태 부여는 정상 처리합니다.

플레이어 카드는 [Ward_PlayerEffect](../Assets/CardData/Status/Examples/Ward_PlayerEffect.asset), 적 자신의 행동은 [BuffWard](../Assets/Enemy/Examples/BuffWard.asset)를 사용합니다. 양쪽 모두 [같은 아이콘](../Assets/Images/UI/StatusIcon/ward.png)을 표시하고, 연속 공격의 피해 예고는 첫 타격만 0으로 계산합니다.

## 카드 설정

1. Project 창에서 `Create → Card → Effect → Apply Status`로 효과 에셋을 생성합니다.
2. Inspector에서 `Target`을 `Player` 또는 `Enemy`로 지정합니다.
3. `Status`에 상태 정의를 연결합니다. `Turns`는 턴제의 기간 또는 화상의 추가 중첩 수이며, `Buff Power`는 버프의 수치입니다. 전투 종료·다음 턴·다음 공격·다음 피격 버프의 지속 조건은 상태 에셋에서 정합니다.
4. 해당 효과 에셋을 `CardData`의 `Effects` 배열에 연결합니다. 다른 카드 효과와 함께 사용할 수 있습니다.

`Assets/CardData/Status/Examples`에는 디버프 예제 카드와 가시·방호막을 플레이어에게 부여하는 효과 예제가 있습니다. 기존 시작 덱과 보상 풀에는 자동으로 추가하지 않습니다.

## 지속 턴과 피해 계산

- **플레이어 턴 시작 시 가장 먼저** 플레이어와 적의 지속 턴 기반 상태이상 남은 턴을 각각 1 줄입니다. 플레이어 턴 상태 전환, 코스트 처리, 방어도 초기화 및 카드 드로우보다 먼저 실행합니다. 0턴이 되면 해제됩니다. 화상 중첩은 턴 시작 처리에서 제외됩니다.
- 기존 턴제 디버프를 다시 부여하면 남은 턴에 추가합니다. 예를 들어 2턴 남은 녹슬음에 3턴을 추가하면 5턴이 됩니다. 피해 배율은 중첩되지 않습니다.
- 플레이어 턴에 부여한 1턴 상태이상은 이번 적 행동까지 유지되고, 다음 플레이어 턴 시작에 해제됩니다. 예를 들어 플레이어에게 건 1턴 약점 노출도 이번 적 공격에 적용됩니다.
- 화상은 플레이어 턴 종료 후 적이 행동하기 전에 플레이어와 적 순으로 처리합니다. 방어도와 공격 피해 배율에 관계없이 중첩 수만큼 HP를 줄인 뒤 중첩을 1 줄입니다. 0중첩이면 해제되며, 피해로 전투가 끝나면 턴 진행도 끝납니다.
- 전투 시작 시 양쪽 캐릭터의 상태이상을 초기화합니다.
- 피해는 공격자의 녹슬음과 대상의 약점 노출을 함께 계산하고, 최종 소수점을 버린 뒤 방어도를 차감합니다. 기본 피해가 10이고 두 상태가 모두 적용되면 `10 × 0.75 × 1.5 = 11.25`에서 피해 11이 됩니다.
- 적 행동 예고에는 적의 녹슬음과 플레이어의 약점 노출이 반영됩니다. 양쪽의 상태 적용·재적용·만료 시 자동 갱신하며, 실제 공격에도 같은 계산을 사용합니다.

## 아이콘 설정

Soldier와 Enemy의 `CharacterInfoUI/StatusContainer`에 활성 상태 아이콘이 나란히 표시됩니다. 오른쪽 아래 숫자는 지속 턴 기반 상태의 남은 턴, 화상의 현재 중첩 수입니다. 지속 턴이 끝나거나 화상 중첩이 0이 되면 해당 아이콘을 제거합니다. 활성 상태·지속 카드·지연 예약 아이콘이 있는 동안에는 아이콘 영역에 맞춰 공용 프레임 배경을 표시합니다. 행이 비면 배경도 숨깁니다.

아이콘 프리팹은 `Assets/Prefabs/UI/StatusIcon.prefab`입니다. 약점 노출·녹슬음·방어 파괴·화상은 각 정의 에셋의 `Icon`으로 `Assets/Images/UI/StatusIcon/`의 이미지를 참조합니다. 화상은 `burn.png`를 사용합니다. 아이콘 크기와 숫자 위치는 프리팹에서 수정할 수 있습니다.

## 상태이상 설명 툴팁

아이콘에 마우스 포인터를 올리면 상태 이름, 효과 설명과 남은 턴이 표시됩니다. 화상은 `중첩: N`을 표시합니다. 상태 수치가 바뀌면 열린 툴팁을 갱신하고, 포인터를 치우거나 아이콘이 만료·비활성화되면 닫습니다.

각 상태 정의 에셋의 `Description`에서 설명을 수정합니다. 약점 노출은 받는 피해 50% 증가, 녹슬음은 공격으로 주는 피해 25% 감소로 설정되어 있습니다.

`StatusEffectsUI`의 `Tooltip Prefab`에는 `Assets/Prefabs/UI/StatusTooltip.prefab`이 연결됩니다. 첫 상태 아이콘 생성 시 최상위 Canvas의 직접 자식으로 툴팁 하나를 생성하고 양쪽 HUD가 공유합니다. StatusContainer 레이아웃에는 포함되지 않습니다. 배경과 텍스트는 포인터 입력을 가로채지 않으며, Canvas 좌표로 포인터 위치를 변환하고 가장자리에서 위치를 조절합니다.

상태 아이콘 툴팁의 남청색 9슬라이스 프레임은 카드 호버와 우클릭 상세창의 상태 설명에도 사용합니다. 프리팹 연결은 [공용 상태 설명 프레임](CardDescriptions.md#공용-상태-설명-프레임)을 참고합니다.

현재 화상 정의 에셋은 구현되어 있으며, 임시 런에서 사용하는 카드·적 행동 에셋에는 연결되지 않았습니다. 아래 화상 테스트는 BattleScene에서 상태를 적용해 전투 처리와 HUD를 검사합니다.

## 검증

Unity 6000.0.85f2에서 방호막의 양쪽 적용, 첫 공격 상쇄, 방어도 보존, 연속 공격 예고, HUD 아이콘 표시·제거를 포함한 관련 검사 133개가 모두 통과했습니다. 결과는 로컬 `.utmp/ward-final.xml`에 있습니다.

Unity 6000.0.85f2에서 버프의 기간·소모, 가시의 방어도 무시 반격과 전투 종료, 기존 디버프·지속 카드·행동 예고를 포함한 관련 검사 129개가 모두 통과했습니다. 결과는 로컬 `.utmp/buff-status-final.xml`에 있습니다.

2026-11-11 Unity 6000.0.85f2에서 화상 관련 테스트 2/2가 통과했습니다. 양쪽 HUD의 스프라이트와 중첩 숫자, 툴팁, 턴 종료 피해와 중첩 감소·만료, 치명적인 화상으로 적 행동 전에 전투가 종료되는 경우를 검사했습니다. 결과는 로컬 `.utmp/burn-icon-20261111/after.xml`에 있습니다.

실제 BattleScene에서 카드 사용, 양쪽 상태 아이콘, 플레이어 턴 시작의 턴 감소·만료, 적 행동 예고와 실제 피해를 검증하는 테스트를 포함합니다. 상태이상 갱신이 턴 상태 전환·방어도 초기화·카드 드로우보다 먼저 실행되는 순서와 UI 비활성화 후 재활성화도 검사합니다.

초기 구현 검증 당시 Unity 6000.0.77f1에서 전체 105개 테스트가 통과했습니다. 추가된 툴팁 테스트 2개는 프리팹·설명 참조와 실제 BattleScene의 포인터 입력, 턴 갱신, 소유자 전환, 만료·비활성화 및 화면 경계 배치를 검사합니다. 공용 프레임 적용 후의 렌더링과 회귀 검증은 [카드 설명 문서](CardDescriptions.md#공용-상태-설명-프레임)에 기록했습니다.
