# 개전 효과

개전은 플레이어 턴에 처음으로 사용에 성공한 카드에만 적용되는 조건입니다.
꿈과 악몽은 개전 기회를 공유합니다. 일반 효과는 그대로 실행하고 `OpeningEffect`의 자식 효과만 조건에 따라 실행합니다.

## 카드 설정

1. Project 창에서 **Create → Card → Effect → Opening**으로 효과 에셋을 생성합니다.
2. `Effects`에 개전 시 실행할 효과를 순서대로 연결합니다.
3. 생성한 효과를 카드의 `CardData.effects`에 연결합니다. 항상 실행할 효과는 바깥에 둡니다.

예를 들어 `effects[0]`에 피해 6의 `DamageEffect`, `effects[1]`에 방어도 4의 `BlockEffect`를 자식으로 가진 `OpeningEffect`를 연결하면 첫 카드일 때 피해 6과 방어도 4를 적용하고, 그 이후에는 피해 6만 적용합니다.

## 설명 토큰

위 예시의 카드 설명은 다음과 같이 작성합니다.

```text
피해를 {damage:0} 줍니다.
개전: 방어도를 {block:1.0} 얻습니다. {openingCondition:1}
```

`{openingCondition:1}`은 `effects[1]`의 개전 가능 여부를 표시합니다. 자식 효과의 수치는 기존 점 구분 인덱스로 지정합니다. 일반 카드 미리보기는 사용 및 턴 전환 시 갱신하며, 사용 중인 카드의 설명은 사용 직전 상태를 유지합니다. 원본 확인 화면에서는 조건 문구를 생략하고 기본 수치를 표시합니다.

## 판정 규칙

- 첫 번째로 사용에 성공한 카드가 개전 속성이 없어도 기회를 소모합니다. 코스트 0 카드도 포함합니다.
- 코스트나 필수 탄약 부족으로 사용에 실패하면 기회를 소모하지 않습니다.
- X 카드는 개전 효과를 발동하지 않습니다. X=0을 포함하여 사용에 성공하면 첫 카드 기회는 소모합니다.
- 카드 사용 순간의 판정을 보관하므로 수동 멀리건 등으로 효과가 잠시 대기해도 결과가 바뀌지 않습니다.
- 지속 카드의 사용 시 효과에도 적용할 수 있습니다. 자식의 지속 효과는 해당 지속 카드에 종속되어 해제됩니다.
- 지속 카드의 매 턴 자동 효과와 지연 예약의 자동 실행은 카드 사용으로 세지 않으며, 그 안의 개전 효과도 발동하지 않습니다.
- **Opening → Delay → 효과**는 첫 카드 사용 시 지연 효과를 예약합니다. **Delay → Opening → 효과**는 예약 실행 시 새 카드 사용이 아니므로 개전 자식을 실행하지 않습니다.
- 턴 시작 시 개전 기회를 초기화하고 전투 종료·비활성화 시 남은 효과 실행 문맥을 정리합니다. 공유 ScriptableObject에는 사용 횟수나 발동 여부를 저장하지 않습니다.

이 변경은 기능과 생성 메뉴를 추가합니다. 기존 카드의 효과 구성이나 밸런스는 변경하지 않습니다.
