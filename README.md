# Unity_ProjectDN

## 현재 플레이 범위

Unity 6000.0.85f2의 2D URP 덱빌딩 전투 프로토타입입니다. 타이틀에서 군인으로 `모험 시작`을 누르면 1층 13노드 런을 시작합니다. 4·6·10번에 엘리트 선택지, 7번에 매개체, 12번에 휴식 선택지, 13번에 보스 전투를 배치합니다. 캐릭터 선택 패널은 페이드 인하며, 모험 시작과 전투 진입에는 공용 남청색 안개 전환이 적용됩니다. 로딩이 0.8초 이상 걸리면 초승달과 안내 문구를 표시합니다. [1층 노드 배치](docs/MapSystem.md#1층-노드-배치와-전투-상한)

- **상점**에서는 진열 카드의 상세보기에서 구매를 확정합니다. 잔액이 가격 이상이면 골드를 차감하고 카드 한 장을 덱에 추가하며, 같은 슬롯에 `SOLD OUT`을 표시합니다. `카드 제거`는 꿈·악몽 런 덱에서 고른 한 장을 제거합니다. 제거 기본가는 100골드에서 시작해 같은 런에서 제거할 때마다 50골드씩 오릅니다. 상인 조합 증표를 보유하면 카드 구매와 제거 가격이 30% 할인됩니다. 악몽 카드와 매개체는 `입고 예정`입니다. [상점 카드 제거](docs/MapSystem.md#상점-카드-제거)
- **휴식**에서는 잃은 체력의 30%를 올림한 값에 10을 더해 최대 HP까지 회복합니다. 여행자의 물통을 보유하면 고정 회복량이 20이 됩니다. 카드 강화를 선택하면 꿈·악몽별 목록에서 한 장을 골라 강화 전후를 비교하고 비용 없이 강화할 수 있습니다. [휴식](docs/MapSystem.md#휴식)
- **미지**는 일반 전투, 층별 이벤트, 상점, 휴식 또는 매개체로 결정됩니다. 선택을 저장한 뒤 안개가 걷히며 결과를 공개합니다. 전투 상한에 도달한 구간에서는 전투 가중치가 이벤트에 더해집니다. [미지 노드](docs/MapSystem.md#미지-노드)
- **매개체(Conduit)**는 군인의 시작 매개체 탄피와 공용 보상 일반 7종·고급 7종을 합해 15종입니다. 엘리트와 미지는 기본 일반 70%·고급 30%로 추첨합니다. 정예 사냥꾼의 훈장을 보유하면 엘리트 추첨에 50:50을 적용합니다. 7번 노드에서는 6번 일반 전투 승리 시 일반, 엘리트 승리 시 고급 매개체를 제시합니다. 보유 매개체는 획득 순서대로 전투 HUD에 표시합니다. [매개체 노드](docs/MapSystem.md#매개체-노드)
- **이어서 하기**는 맵 진행, 확정한 조우와 미지 결과, 보유 매개체, 비전투 노드 입장 상태, 전투 입장 또는 보상 처리 단계를 복원합니다. [체크포인트](docs/RunCheckpoints.md)

**카드 아트워크**는 군인의 꿈 시작 카드 4종과 꿈 보상 카드 18종의 원본·강화 카드에 적용했습니다. [Unity 적용 위치](ToDo_List.md#군인-보상-카드-아트워크)

**방어도 획득 연출**은 플레이어와 적이 방어도를 얻을 때 방패와 실제 획득량을 표시합니다. [캐릭터 HUD](docs/CharacterPresentation.md#방어도-획득-연출)

**1층 조우**에는 전반부 일반 적 4종, 후반부 일반 적 5종, 엘리트 전용 적 3종을 배치했습니다. 접힌 종이병정·재봉거미·뒤집힌 모래시계를 비롯한 신규 9종의 스프라이트와 대기 애니메이션을 연결했으며, 현재 전투는 공용 테스트 행동을 사용합니다. [조우 목록](docs/MapSystem.md#조우-순서) · [적 아트와 미리보기](docs/CharacterPresentation.md#신규-적-스프라이트와-대기-애니메이션)

**전투 상태**는 버프와 디버프로 분류합니다. 가시 덤불은 전투 시작 시 가시 3을, 방호막 발생기는 방호막 1을 부여합니다. 방청유는 녹슬음을 막고, 약점 각인기는 카드가 적에게 부여하는 턴제 약점 노출의 지속 시간을 1턴 늘립니다. [상태 규칙](docs/StatusEffects.md#버프와-디버프)

**타이틀 옵션**은 우상단 X 또는 ESC로 닫으며, 설정 초기화 버튼은 하단 중앙에 있습니다. 종료 확인창은 포인터가 올라간 버튼을 강조합니다. 전투에서 패배하면 군인의 쓰러짐 애니메이션 뒤에 도달 지점과 마지막 조우를 보여 주는 패배 패널이 열립니다. [타이틀](docs/TitleMenu.md) · [패배 연출](docs/CharacterPresentation.md#군인-패배-연출)

**포인터**는 타이틀·맵·전투에서 기본과 호버 상태를 사용합니다. 효과음 음량 설정과 연출 재생 단계가 있으며, 공용 재생기와 게임 전반의 효과음 적용은 작업 목록에 있습니다. [마우스 포인터](docs/TitleMenu.md#마우스-포인터) · [효과음 작업 목록](ToDo_List.md#게임-효과음)
