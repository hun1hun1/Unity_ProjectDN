# Unity_ProjectDN

## 현재 플레이 범위

Unity 6000.0.85f2의 2D URP 덱빌딩 전투 프로토타입입니다. 타이틀에서 군인을 선택하고 `모험 시작`을 누르면 한 층 5개 지점의 런이 시작됩니다. 각 지점에는 일반 전투가 있고, 3번째에는 상점, 4번째에는 휴식도 선택할 수 있습니다. 캐릭터 선택 패널은 페이드 인하며, 모험 시작과 전투 진입에는 공용 남청색 안개 전환이 적용됩니다. 로딩이 0.8초 이상 걸리면 초승달과 안내 문구를 표시합니다.

- **상점**에서는 진열 카드의 상세보기에서 구매를 확정합니다. 잔액이 가격 이상이면 골드를 차감하고 카드 한 장을 덱에 추가하며, 같은 슬롯에 `SOLD OUT`을 표시합니다. 악몽 카드와 매개체는 `입고 예정`이며, 카드 제거는 준비 중입니다.
- **휴식**에서 선택 직전에 잃은 체력의 30%를 올림한 값에 10을 더해 최대 HP까지 회복합니다. 체력 회복 대신 꿈·악몽별 강화 목록에서 한 장을 골라 강화 전후를 비교하고 비용 없이 강화할 수 있습니다.
- **이어서 하기**는 맵 진행, 상점·휴식 입장 상태, 전투 입장 또는 보상 처리 단계를 복원합니다.

**카드 아트워크**는 군인 스프라이트를 바탕으로 재충전·박격포 포격·폭격 요청의 신규 PNG 3종을 제작해 Unity의 기본·강화 카드에 연결했습니다. [원본 파일과 Unity 적용 위치](ToDo_List.md#군인-보상-카드-아트워크)에 정리했습니다.
