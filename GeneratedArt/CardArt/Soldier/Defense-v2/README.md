# 군인 방어 카드 아트워크 v2

철모가 떨어지는 돌과 금속 파편을 튕겨내는 새로운 중앙 구도입니다. 기존 군인의 철모와 도색 스타일을 참고했으며, 밝은 황갈색 먼지와 폐허를 배경으로 사용했습니다. 인물과 적의 모습은 등장하지 않습니다.

검은 배경·소총 대각선 구도·총알을 막는 장면에 한정할 필요가 없다는 요청을 반영했습니다. v1과 별도로 저장했습니다.

- `soldier-defense-original.png`: 생성 원본
- `soldier-defense-900x520.png`: 카드 영역 비율의 고해상도 PNG
- `soldier-defense-180x104.png`: 기본 카드 아트워크 영역 크기의 PNG
- `prompt.txt`: 실제 생성 프롬프트
- `asset-info.json`: 파일 크기와 스타일 참고 정보

기본 제공 `image_gen`으로 제작했습니다. 이번 작업에서는 Unity 카드 데이터의 artwork 참조를 변경하지 않았습니다.
