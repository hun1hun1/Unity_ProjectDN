# 군인 방어 카드 아트워크 v1

우상단 어둠 속에서 날아오는 탄환을 좌하단의 두꺼운 군용 철판이 막는 장면입니다. 청회색 철판의 탄흔과 주황색 도탄 불꽃으로 방어를 표현했습니다. 철판 뒤에는 소총 일부만 보이며, 군인과 적의 신체·윤곽은 등장하지 않습니다.

- `soldier-defense-original.png`: 생성 원본
- `soldier-defense-900x520.png`: 카드 영역 비율의 고해상도 PNG
- `soldier-defense-180x104.png`: 기본 카드 아트워크 영역 크기의 PNG
- `prompt.txt`: 실제 생성 프롬프트
- `asset-info.json`: 파일 크기와 스타일 참고 정보

기본 제공 `image_gen`으로 공격 카드 v2의 검은 배경과 도색 스타일에 맞춰 제작했습니다. 이번 작업에서는 Unity 카드 데이터의 artwork 참조를 변경하지 않았습니다.
