# 표적 추적 카드 아트워크 v1

땅바닥에 도마뱀 발자국 세 개가 대각선으로 이어지는 구도입니다. 발톱과 발가락이 눌린 어두운 홈, 흙 가장자리의 빛으로 발자국이 작은 카드에서도 보이도록 표현했습니다. 기존 군인 카드의 거친 도색 질감과 차분한 흙·올리브·회색 색감을 유지했습니다.

- `target-tracking-original.png`: 생성 원본.
- `target-tracking-900x520.png`: 고해상도 카드 아트워크, 900×520.
- `target-tracking-180x104.png`: 기본 카드 아트워크 영역 크기, 180×104.
- `prompt.txt`: 실제 생성 프롬프트.
- `asset-info.json`: 파일 크기와 변환 정보.

기본 제공 `image_gen` 도구로 제작했습니다. 원본을 보존하고 중앙 기준으로 카드 영역 비율에 맞춘 뒤 Lanczos 방식으로 두 가지 크기를 내보냈습니다. Unity 카드 데이터의 artwork 참조는 변경하지 않았습니다.
