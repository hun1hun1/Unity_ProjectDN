# 군인 공격 카드 아트워크 v2

v1의 소총과 좌하단→우상단 사격 구도를 유지하고, 원형 표적과 야외 풍경을 검은 그림자 배경으로 교체했습니다. 어둠 속에 숨은 적을 향해 발사하는 장면이며, 적의 윤곽·눈·신체는 드러내지 않습니다. 우상단의 작은 탄착 불꽃과 연기로 공격 방향을 표현했습니다.

- `soldier-attack-original.png`: 편집 원본
- `soldier-attack-900x520.png`: 카드 영역 비율의 고해상도 PNG
- `soldier-attack-180x104.png`: 기본 카드 아트워크 영역 크기의 PNG
- `prompt.txt`: 실제 편집 프롬프트
- `asset-info.json`: 파일 크기와 원본 버전 정보

기본 제공 `image_gen`으로 v1을 편집했습니다. v1 파일은 보존했으며, 이번 작업에서는 Unity 카드 데이터의 artwork 연결을 변경하지 않았습니다.
