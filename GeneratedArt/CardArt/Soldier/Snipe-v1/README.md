# 저격 카드 아트워크 v1

제공된 조준경 스케치의 구도를 바탕으로 원형 조준경과 십자선의 중앙에 검은 적 실루엣을 배치했습니다. 기존 방어 카드의 거친 도색 질감과 어두운 올리브·회색 색감을 참고했습니다.

- `snipe-original.png`: 생성 원본.
- `snipe-900x520.png`: 고해상도 카드 아트워크, 900×520.
- `snipe-180x104.png`: 기본 카드 아트워크 영역 크기, 180×104.
- `composition-reference.png`: 사용자가 제공한 투명 배경 스케치.
- `prompt.txt`: 실제 생성 프롬프트.
- `asset-info.json`: 파일 크기와 참조·변환 정보.

기본 제공 `image_gen` 도구로 제작했습니다. 원본을 보존하고 중앙 기준으로 카드 영역 비율에 맞춘 뒤 Lanczos 방식으로 두 가지 크기를 내보냈습니다. Unity 카드 데이터의 artwork 참조는 변경하지 않았습니다.
