# 군인 방어 카드 아트워크 v3

기존 군인 캐릭터의 복장과 그림체를 참고한 근접 방어 장면입니다. 군인이 몸을 낮추고 소총을 가로로 들어 위에서 내려오는 칼날을 금속 부위로 받아내며, 충돌 지점의 불꽃으로 방어를 표현했습니다. 철모를 눌러쓴 모습과 올리브색 군복, 목재 소총, 탄입대를 유지했습니다.

카드 아트워크 크기와 군인 콘셉트에 맞춰 새로운 구도로 제작했습니다. 배경은 자연광의 전장 폐허이며, 마법 방벽이나 검은 배경은 사용하지 않았습니다.

- `soldier-defense-original.png`: 생성 원본
- `soldier-defense-900x520.png`: 카드 영역 비율의 고해상도 PNG
- `soldier-defense-180x104.png`: 기본 카드 아트워크 영역 크기의 PNG
- `prompt.txt`: 실제 생성 프롬프트
- `asset-info.json`: 파일 크기와 캐릭터 참고 정보

기본 제공 `image_gen`으로 제작했습니다. 기존 버전은 보존했으며, Unity 카드 데이터의 artwork 참조는 변경하지 않았습니다.
