# 군인 방어 카드 아트워크 v4

방탄방패 표면에 허수아비가 할퀸 세 줄의 자국이 남아 있는 장면입니다. 도색이 벗겨진 금속 가장자리와 홈에 걸린 소량의 짚·나무 조각으로 공격의 흔적을 표현했습니다. 군인과 허수아비를 비롯한 캐릭터, 손, 발톱 자체는 그리지 않았습니다.

기존 허수아비의 세 갈래 나무 손톱과 군인 카드의 도색 스타일을 참고했습니다. 배경은 흐릿한 전장 폐허이며, 실제 카드 아트워크 영역인 180×104 비율로 내보냈습니다.

- `soldier-defense-original.png`: 생성 원본
- `soldier-defense-900x520.png`: 카드 영역 비율의 고해상도 PNG
- `soldier-defense-180x104.png`: 기본 카드 아트워크 영역 크기의 PNG
- `prompt.txt`: 실제 생성 프롬프트
- `asset-info.json`: 파일 크기와 제작 정보

기본 제공 `image_gen`으로 제작했습니다. 기존 버전은 보존했으며 Unity 카드 데이터의 artwork 참조는 변경하지 않았습니다.
