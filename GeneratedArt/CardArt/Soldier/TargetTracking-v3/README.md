# 표적 추적 카드 아트워크 v3

돋보기를 흙바닥 위로 띄우고 떨어진 그림자로 지면과의 거리를 표현했습니다. 렌즈 안의 발자국과 흙 무늬를 크게 확대해 돋보기의 역할이 드러나도록 수정했습니다.

- `target-tracking-original.png`: 편집 결과 원본.
- `target-tracking-900x520.png`: 고해상도 카드 아트워크, 900×520.
- `target-tracking-180x104.png`: 기본 카드 아트워크 영역 크기, 180×104.
- `prompt.txt`: 실제 편집 프롬프트.
- `asset-info.json`: 파일 크기와 변환 정보.

기본 제공 `image_gen` 도구로 v2를 편집했습니다. 원본을 보존하고 중앙 기준으로 카드 영역 비율에 맞춘 뒤 Lanczos 방식으로 두 가지 크기를 내보냈습니다. 기존 버전과 Unity 카드 데이터는 변경하지 않았습니다.
