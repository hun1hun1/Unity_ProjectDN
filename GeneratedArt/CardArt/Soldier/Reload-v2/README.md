# 재장전 카드 아트워크 v2

v1의 탄창과 상단에 장전된 탄, 기존 구도를 유지하면서 천 배경을 단순한 어두운 배경으로 교체했습니다.

- `reload.png`: 편집 결과 PNG, 1649×954.
- `prompt.txt`: 실제 편집 프롬프트.

기본 제공 `image_gen` 도구로 v1 이미지를 편집했습니다. 배경은 불투명하며, 기존 v1과 Unity 카드 데이터는 유지했습니다.

## 카드 아트워크 크기

- `reload-900x520.png`: 고해상도 카드 아트워크, 900×520.
- `reload-180x104.png`: 기본 카드 아트워크 영역 크기, 180×104.
- `asset-info.json`: 원본과 출력 파일의 크기 및 변환 정보.

원본을 보존하고 중앙 기준으로 카드 영역 비율에 맞춘 뒤 Lanczos 방식으로 축소했습니다. 그림을 다시 생성하거나 늘이지 않았습니다. Unity 카드 데이터의 참조는 변경하지 않았습니다.
