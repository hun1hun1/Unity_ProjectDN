# 재장전 카드 아트워크 v1

기존 군인 카드의 어두운 올리브·회색 색감과 거친 도색 질감에 맞춘 탄창 아트워크입니다. 탄창 상단의 급탄구에 장전된 황동 탄피와 구리색 탄두가 보이도록 비스듬히 내려다보는 구도로 제작했습니다. 인물, 손, 총기와 별도 소품은 포함하지 않았습니다.

- `reload.png`: 생성 원본 PNG, 1649×954.
- `prompt.txt`: 실제 생성 프롬프트.

기본 제공 `image_gen` 도구로 제작했으며 추가 이미지 편집이나 크기 변경은 하지 않았습니다. Unity 카드 데이터의 artwork 참조는 변경하지 않았습니다.
