# 부식 카드 아트워크 v1

기존 군인 카드의 어두운 색감, 거친 도색 질감과 검은 외곽선을 참고해 부식된 군용 칼 한 자루를 제작했습니다. 칼날의 붉은 녹, 깊게 패인 구멍과 손상된 날로 부식을 표현했습니다. 인물과 다른 무기는 포함하지 않았습니다.

- `corrosion.png`: 생성 원본 PNG, 1650×953. 생성 원본을 유지했습니다.
- `prompt.txt`: 실제 생성 프롬프트.

기본 제공 `image_gen` 도구로 제작했습니다. 기존 양날의 검과 방어 이미지를 열어 스타일을 확인한 뒤 프롬프트에 반영했습니다. Unity 카드 데이터의 artwork 참조는 변경하지 않았습니다.

## 카드 아트워크 크기

- `corrosion-900x520.png`: 고해상도 카드 아트워크, 900×520.
- `corrosion-180x104.png`: 기본 카드 아트워크 영역 크기, 180×104.
- `asset-info.json`: 원본과 출력 파일의 크기 및 변환 정보.

원본을 보존하고 중앙 기준으로 카드 영역 비율에 맞춘 뒤 Lanczos 방식으로 축소했습니다. 그림을 다시 생성하거나 늘이지 않았습니다. Unity 카드 데이터의 참조는 변경하지 않았습니다.
