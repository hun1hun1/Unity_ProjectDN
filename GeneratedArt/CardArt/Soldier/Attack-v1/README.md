# 군인 공격 카드 아트워크 v1

좌하단의 M1 개런드 형태 소총이 우상단 원형 표적을 향해 사격하는 구도입니다. 군인·적·손·팔은 등장하지 않으며, 카드 테두리와 문구도 포함하지 않았습니다. 기존 군인 그림과 같은 굵은 외곽선, 붓 질감, 올리브색·갈색 계열의 도색을 사용했습니다.

## 파일

- `soldier-attack-original.png`: 생성 원본
- `soldier-attack-900x520.png`: 카드 아트워크 영역 비율에 맞춘 고해상도 파일
- `soldier-attack-180x104.png`: 기본 카드 크기의 아트워크 영역에 맞춘 파일
- `prompt.txt`: 실제 생성 프롬프트
- `asset-info.json`: 파일 크기와 슬롯 정보

현재 `Assets/Prefabs/UI/Card.prefab`의 기본 크기는 200×260이고, Artwork의 앵커는 `(0.05, 0.425)`~`(0.95, 0.825)`이므로 기본 표시 영역은 180×104입니다. 전체 배경이 있는 불투명 아트워크로 제작했습니다.

기본 제공 `image_gen`으로 생성한 뒤 크기별 PNG를 내보내고 구도를 확인했습니다. 이번 작업은 이미지 제작이며, Unity 카드 데이터의 artwork 참조는 변경하지 않았습니다.
