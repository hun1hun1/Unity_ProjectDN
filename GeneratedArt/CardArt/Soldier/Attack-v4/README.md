# 군인 공격 카드 아트워크 v4

v3에서 총알이 휘는 것처럼 보이던 부분을 수정했습니다. 우측의 탄착 불꽃을 왼쪽으로 옮기고 총구에서 이어지는 짧은 연기 방향을 정리했습니다. 좌하단은 밝고 우상단은 어두운 명암과 소총 구도는 유지했습니다.

- `soldier-attack-original.png`: 편집 원본
- `soldier-attack-900x520.png`: 카드 영역 비율의 고해상도 PNG
- `soldier-attack-180x104.png`: 기본 카드 아트워크 영역 크기의 PNG
- `prompt.txt`: 실제 편집 프롬프트
- `asset-info.json`: 파일 크기와 원본 버전 정보

기본 제공 `image_gen`으로 v3를 편집했습니다. 기존 버전은 보존했으며, Unity 카드 데이터의 artwork 참조는 변경하지 않았습니다.
