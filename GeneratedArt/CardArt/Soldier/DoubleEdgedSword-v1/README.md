# 양날의 검 카드 아트워크 v1

거친 군용 천과 잔해 위에 놓인 양날검을 중심으로 제작했습니다. 양쪽 날에 차가운 은청색 반사광과 붉은 반사광을 대비시켜 공격의 위력과 자신에게 돌아오는 위험을 함께 표현했습니다. 기존 군인 카드와 같은 굵은 외곽선과 거친 도색 질감을 사용했습니다.

- `double-edged-sword-original.png`: 생성 원본
- `double-edged-sword-900x520.png`: 카드 영역 비율의 고해상도 PNG
- `double-edged-sword-180x104.png`: 기본 카드 아트워크 영역 크기의 PNG
- `prompt.txt`: 실제 생성 프롬프트
- `asset-info.json`: 크기와 제작 정보

기본 제공 `image_gen`으로 제작했습니다. 현재 카드 프리팹의 180×104 아트워크 비율에 맞춰 내보냈으며, Unity 카드 데이터의 artwork 참조는 변경하지 않았습니다.
