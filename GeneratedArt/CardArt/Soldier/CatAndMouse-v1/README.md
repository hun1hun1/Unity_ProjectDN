# 병 주고 약 주기 카드 아트워크 v1

방패 뒤에서 자신을 지키는 군인이 적 슬라임에게 회복약을 부어주는 반어적인 장면입니다. 현재 카드 효과인 자신의 방어도 획득과 적의 체력 회복을 반영했습니다. 슬라임의 반창고와 의심스러운 표정, 군인의 작은 미소로 카드의 익살스러운 분위기를 표현했습니다.

기존 군인과 슬라임의 외형, 굵은 외곽선, 거친 도색 질감을 참고했습니다.

- `cat-and-mouse-original.png`: 생성 원본
- `cat-and-mouse-900x520.png`: 카드 영역 비율의 고해상도 PNG
- `cat-and-mouse-180x104.png`: 기본 카드 아트워크 영역 크기의 PNG
- `prompt.txt`: 실제 생성 프롬프트
- `asset-info.json`: 크기와 제작 정보

기본 제공 `image_gen`으로 제작했습니다. 현재 카드 프리팹의 180×104 아트워크 비율에 맞춰 내보냈으며, Unity 카드 데이터의 artwork 참조는 변경하지 않았습니다.
