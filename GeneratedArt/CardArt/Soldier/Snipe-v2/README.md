# 저격 카드 아트워크 v2

조준경과 폐허 배경은 유지하고, 중앙의 사람 형태 적을 네 발과 긴 꼬리를 가진 검은 괴물 실루엣으로 바꿨습니다.

- `snipe-original.png`: 편집 결과 원본.
- `snipe-900x520.png`: 고해상도 카드 아트워크, 900×520.
- `snipe-180x104.png`: 기본 카드 아트워크 영역 크기, 180×104.
- `prompt.txt`: 실제 편집 프롬프트.
- `asset-info.json`: 파일 크기와 변환 정보.

기본 제공 `image_gen` 도구로 v1을 편집했습니다. 원본을 보존하고 중앙 기준으로 카드 영역 비율에 맞춘 뒤 Lanczos 방식으로 두 가지 크기를 내보냈습니다. 기존 버전과 Unity 카드 데이터는 변경하지 않았습니다.
