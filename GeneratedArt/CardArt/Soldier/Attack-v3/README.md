# 군인 공격 카드 아트워크 v3

공격 카드 v2의 소총과 사격 구도를 유지하면서 조명을 수정했습니다. 좌하단의 플레이어 측은 따뜻하고 밝게, 우상단의 공격을 받는 측은 짙은 어둠으로 표현했습니다. 왼쪽 주변 배경도 함께 밝히고, 중앙에서 오른쪽으로 자연스럽게 어두워지도록 구성했습니다. 적의 형체는 계속 드러내지 않습니다.

- `soldier-attack-original.png`: 편집 원본
- `soldier-attack-900x520.png`: 카드 영역 비율의 고해상도 PNG
- `soldier-attack-180x104.png`: 기본 카드 아트워크 영역 크기의 PNG
- `prompt.txt`: 실제 편집 프롬프트
- `asset-info.json`: 파일 크기와 원본 버전 정보

기본 제공 `image_gen`으로 v2를 편집했습니다. 기존 버전은 보존했으며, 이번 작업에서는 Unity 카드 데이터의 artwork 참조를 변경하지 않았습니다.
