# Rare 희귀도 이름 패널 v1

기존 RareRarity.png의 밝은 노란색(#FFF200) 계열을 유지한 이름 패널입니다. 일반 및 고급 패널과 같은 비율, 얇은 금속 테두리, 살짝 잘린 모서리 구조로 제작했습니다. 중앙은 검은 이름 글자가 읽히도록 문양 없이 넓게 구성했습니다. 생성 이미지이므로 테두리의 세부 질감은 기존 패널과 차이가 있습니다.

| 파일 | 크기 | 용도 |
|---|---|---|
| rare-nameplate-930x156.png | 930×156 | 6배 고해상도 소재 |
| rare-nameplate-310x52.png | 310×52 | 2배 소재 |
| rare-nameplate-155x26.png | 155×26 | 기본 이름 패널 크기 |
| rare-nameplate-readability-preview.png | 1002×792 | 빈 패널과 이름 글자 미리보기 |
| rare-nameplate-original.png | 생성 원본 크기 | 생성 원본 |
| prompt.txt | — | 실제 생성 프롬프트 |
| asset-info.json | — | 치수, 색상, 투명도 및 가독성 측정 |

세 가지 소재 PNG에는 글자가 없습니다. 바깥은 투명하며 이름 영역은 노란색으로 채워져 있습니다. 200×260 카드의 이름 패널 크기인 155×26 비율로 내보냈습니다.

미리보기는 프로젝트 Noto Sans KR 글꼴, 검은 굵은 글자, 논리 크기 20을 사용한 이미지 조합입니다. Unity 실행 화면이 아니며 Image 알파 1 기준입니다. 미리보기의 글자와 배경은 소재 PNG에 포함되지 않습니다.

기본 제공 image_gen으로 일반 패널과 기존 RareRarity.png를 참조해 생성한 뒤, 투명 여백을 추출하고 지정 크기로 내보냈습니다. 프리팹과 기존 희귀도 이미지는 변경하지 않았습니다.
