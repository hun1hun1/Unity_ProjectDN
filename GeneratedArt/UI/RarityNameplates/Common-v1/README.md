# 일반 희귀도 이름 패널 v1

기존 일반 등급 이미지의 무채색 회색(#7F7F7F) 계열을 유지한 이름 패널입니다. 중앙은 검은 이름 글자가 읽히도록 조용하고 균일한 회색으로 두고, 금속 질감과 윤곽은 얇은 가장자리에만 배치했습니다. 색이 들어간 장식과 문양은 넣지 않았습니다.

## 파일

| 파일 | 크기 | 용도 |
|---|---|---|
| `common-nameplate-930x156.png` | 930×156 | 6배 고해상도 소재 |
| `common-nameplate-310x52.png` | 310×52 | 2배 소재 |
| `common-nameplate-155x26.png` | 155×26 | 기본 이름 패널 크기 |
| `common-nameplate-readability-preview.png` | 1002×792 | 빈 패널 및 이름 글자 가독성 미리보기 |
| `common-nameplate-original.png` | 1933×813 | 생성 원본 |
| `prompt.txt` | — | 실제 생성 프롬프트 |
| `asset-info.json` | — | 치수, 명도 및 미리보기 글자 크기 확인 결과 |

세 가지 소재 PNG에는 글자가 없습니다. 바깥은 투명하고 중앙의 이름 영역은 회색으로 채워져 있습니다. 미리보기의 글자는 확인용이며 소재에 포함되지 않습니다.

현재 기본 카드 200×260에서 NamePanel 앵커가 `(0.175, 0.85)`~`(0.95, 0.95)`이므로 크기는 155×26입니다. 같은 비율로 내보내 크기 변경 시 과도한 변형을 줄였습니다.

가독성 미리보기에는 프로젝트의 Noto Sans KR 글꼴과 검은색 굵은 글자, 논리 크기 20을 사용했습니다. `공격`, `양날의 검`, `병 주고 약 주기`가 패널 안에 들어가는 것을 확인했습니다. 이는 Unity에서 실행한 화면이 아니라 이미지 조합 미리보기입니다.

미리보기는 Image 색상 알파 1을 기준으로 합니다. 현재 프리팹의 알파 0.392를 유지하면 뒷면 색과 섞여 보이는 결과가 달라집니다. 이번 작업에서는 프리팹과 코드 및 기존 CommonRarity 이미지를 변경하지 않았습니다.

기본 제공 `image_gen`으로 원본을 생성한 뒤 패널 부분을 추출하고 실제 이름 패널 비율로 내보냈습니다.
