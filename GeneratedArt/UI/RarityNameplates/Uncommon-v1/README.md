# 고급 희귀도 이름 패널 v1

기존 고급 희귀도 이미지의 하늘색 계열(#00A2E8)을 유지한 이름 패널입니다. 일반 희귀도 패널을 참조해 얇은 금속 테두리와 모서리 형태를 맞추고, 중앙은 검은 이름 글자가 읽히도록 넓고 차분하게 구성했습니다.

| 파일 | 크기 | 용도 |
|---|---|---|
| uncommon-nameplate-930x156.png | 930×156 | 6배 고해상도 소재 |
| uncommon-nameplate-310x52.png | 310×52 | 2배 소재 |
| uncommon-nameplate-155x26.png | 155×26 | 기본 이름 패널 크기 |
| uncommon-nameplate-readability-preview.png | 1002×792 | 빈 패널과 이름 글자 미리보기 |
| uncommon-nameplate-original.png | 생성 원본 크기 | 생성 원본 |
| prompt.txt | — | 실제 생성 프롬프트 |
| asset-info.json | — | 치수, 색상, 투명도 및 가독성 측정 |

세 가지 소재 PNG에는 글자가 없습니다. 패널 바깥은 투명하고 이름 영역은 불투명합니다. 200×260 카드의 NamePanel 크기인 155×26에 맞춰 내보냈습니다.

미리보기에는 프로젝트의 Noto Sans KR 글꼴, 검은 굵은 글자, 논리 크기 20을 사용했습니다. 글자와 미리보기 배경은 소재 PNG에 포함되지 않습니다. Unity 실행 화면이 아닌 이미지 조합 미리보기이며 Image 알파 1을 기준으로 합니다.

기본 제공 image_gen으로 일반 패널과 기존 UncommonRarity.png를 참조해 생성한 뒤, 투명 여백을 추출하고 이름 패널 비율로 내보냈습니다. 프로젝트 프리팹과 기존 희귀도 이미지는 변경하지 않았습니다.
