# 공용 방어도 아이콘 v1

HP바 왼쪽의 방어도 수치를 표시하는 방패 아이콘입니다. 기존 공용 HP바와 같은 어두운 철제 프레임과 황동색 선을 사용했으며, 내부는 붉은 체력과 구별되는 짙은 청회색으로 구성했습니다. 플레이어와 적이 공용으로 사용할 수 있도록 진영 문양은 넣지 않았습니다.

## 제공 파일

| 파일 | 크기 | 용도 |
|---|---|---|
| `defense-icon-512.png` | 512×512 | 고해상도 투명 PNG |
| `defense-icon-256.png` | 256×256 | 일반 용도 투명 PNG |
| `defense-icon-128.png` | 128×128 | 축소본 |
| `defense-icon-64.png` | 64×64 | 소형 표시용 |
| `defense-slot-416x294.png` | 416×294 | 기존 방어도 표시 영역 비율에 맞춘 투명 캔버스 |
| `defense-hp-layout-preview.png` | 1242×120 | 방어도 12와 HP 60/100을 겹친 배치 미리보기 |
| `defense-preview.png` | 1322×640 | 아이콘 확대 및 HP바와의 조합 미리보기 |
| `defense-source.png` | 1254×1254 | 생성 원본 |
| `asset-info.json` | — | 크기·알파 검사 결과 |
| `prompt.txt` | — | 실제 생성 프롬프트 |

아이콘 PNG에는 숫자가 없습니다. 중앙의 넓은 청회색 판 위에 방어도 텍스트를 별도로 표시하는 방식입니다. 숫자가 포함된 파일은 이름에 `preview`가 있는 배치 미리보기뿐입니다.

현재 일반 캐릭터의 정보 UI는 320×84이고, Block 영역의 앵커는 가로 0.01~0.14, 세로 0.65~1입니다. 논리 크기는 약 41.6×29.4이며, `defense-slot-416x294.png`는 이 비율에 맞춰 방패가 찌그러지지 않게 여백을 포함했습니다. 정사각형 아이콘을 사용하는 경우에는 비율 유지 설정으로 배치할 수 있습니다. 두 자리·세 자리 수는 실제 표시 크기에 맞춰 글자 크기를 조절합니다.

도색 이미지는 기본 제공 `image_gen`으로 생성했습니다. 크기별 PNG로 내보내고 투명 배경, 중앙 판의 알파, HP바와의 조합을 확인했습니다. 이후 2026-10-22에 `defense-slot-416x294.png`를 `Assets/Images/UI/CharacterHUD/Defense.png`로 가져와 공용 HUD와 기존 캐릭터 프리팹에 적용했습니다. 숫자는 TMP 텍스트로 별도 표시하며, 방어도 0일 때 숨기는 기존 동작을 유지합니다. `ProjectDN/Apply Shared HUD Artwork` 메뉴로 원본을 다시 적용할 수 있습니다.
