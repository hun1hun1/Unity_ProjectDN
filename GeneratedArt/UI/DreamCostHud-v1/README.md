# BattleScene DreamCost HUD v1

상단에 푸른 초승달 장식이 붙은 원형 철제 꿈 자원 계기판입니다. 중앙은 짙은 남색의 조용한 표면으로 비워 두고, 푸른 장식과 마모는 테두리에 집중했습니다. 현재/최대 코스트 텍스트를 별도로 올려 사용하는 소재입니다.

| 파일 | 크기 | 용도 |
|---|---|---|
| dream-cost-hud-1152x972.png | 1152×972 | 6배 고해상도 소재 |
| dream-cost-hud-384x324.png | 384×324 | 2배 소재 |
| dream-cost-hud-192x162.png | 192×162 | 기준 해상도에서의 기본 패널 크기 |
| dream-cost-hud-original.png | 생성 원본 크기 | 원본 이미지 |
| dream-cost-hud-readability-preview.png | 1216×1036 | 빈 패널, 3/3, 0/3, 10/10 미리보기 |
| prompt.txt | — | 실제 생성 프롬프트 |
| asset-info.json | — | 치수, 색상, 투명도와 미리보기 설정 |

소재 PNG에는 숫자와 글자가 없습니다. 바깥은 투명하며 중앙은 남색으로 채워져 있습니다. BattleScene의 DreamCost는 1920×1080 기준 약 192×162이며, 이 캔버스 안에 약 150×150 영역으로 본체와 초승달을 배치했습니다. 실제 화면 비율에 따라 패널의 표시 크기는 달라질 수 있습니다.

미리보기는 Noto Sans KR Bold 원본 OTF, 논리 크기 36, 아이보리색 #F2ECD8, Image 알파 1을 기준으로 만든 이미지 조합입니다. 숫자는 소재 PNG에 포함되지 않으며 Unity 실행 화면은 아닙니다. 미리보기 순서는 왼쪽 위 빈 패널, 오른쪽 위 3/3, 왼쪽 아래 0/3, 오른쪽 아래 10/10입니다.

기본 제공 image_gen으로 제작하고 카드용 꿈 코스트 토큰을 금속 재질 참조로 사용했습니다. 생성 후 투명 여백을 추출하고 패널 규격으로 내보냈습니다. 현재 DreamCostText의 파란 글자색과 달리 본 소재는 밝은 아이보리색 글자용으로 제작되었습니다. BattleScene과 Assets 내 파일은 변경하지 않았습니다.
