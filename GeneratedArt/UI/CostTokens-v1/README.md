# 꿈·악몽 코스트 토큰 v1

중앙은 밝은 은회색, 가장자리는 얇은 철제 링으로 구성한 원형 코스트 토큰입니다. 꿈용은 푸른색, 악몽용은 붉은색 테두리로 구분합니다. 원형의 숫자 영역은 비워 두고 마모는 가장자리에 제한했습니다.

| 파일 | 크기 | 용도 |
|---|---|---|
| dream-cost-token-560x520.png | 560×520 | 꿈 코스트, 20배 고해상도 |
| nightmare-cost-token-560x520.png | 560×520 | 악몽 코스트, 20배 고해상도 |
| 각각의 *-56x52.png | 56×52 | 2배 소재 |
| 각각의 *-28x26.png | 28×26 | 기본 코스트 슬롯 크기 |
| 각각의 *-original.png | 생성 원본 크기 | 원본 이미지 |
| cost-tokens-preview.png | 1192×568 | 왼쪽 꿈, 오른쪽 악몽 소재 미리보기 |
| cost-tokens-readability-preview.png | 1192×1704 | 검은색 1·3·X 가독성 미리보기 |
| dream-prompt.txt / nightmare-prompt.txt | — | 실제 생성 프롬프트 |
| 각각의 *-info.json / preview-info.json | — | 치수, 투명도 및 미리보기 설정 |

소재 PNG에는 숫자나 글자가 없고 바깥은 투명합니다. 기본 카드 200×260에서 CostImage 앵커 (0.03, 0.85)~(0.17, 0.95)에 해당하는 28×26 슬롯에 맞춰 원형을 중앙 배치했습니다. 정사각형 원형 소재를 슬롯에 맞게 투명 여백으로 배치했으므로 내보낸 PNG 자체의 가로세로 비율을 유지하면 됩니다.

가독성 미리보기는 프로젝트의 Noto Sans KR, 검은 굵은 글자, 논리 크기 25, Image 알파 1을 기준으로 한 이미지 조합입니다. 미리보기의 숫자 및 배경은 소재에 포함되지 않으며 실제 Unity 실행 화면은 아닙니다.

기본 제공 image_gen으로 꿈 토큰을 생성하고 이를 참조해 악몽 토큰을 제작했습니다. 기존 일반 희귀도 이름 패널은 금속 재질의 스타일 참조로만 사용했습니다. 생성 후 투명 여백을 추출하고 지정 크기로 내보냈습니다. Assets 내 이미지, 프리팹 및 코드는 변경하지 않았습니다.
