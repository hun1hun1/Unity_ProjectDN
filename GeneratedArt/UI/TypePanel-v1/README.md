# 카드 타입 패널 v1

밝은 회색에 약한 카키색이 섞인 무광 군용 분류 태그입니다. 양끝 모서리를 살짝 사선으로 자르고, 얇은 짙은 회색 윤곽과 끝부분의 미세한 마모만 넣었습니다. 중앙은 검은 타입 글자가 읽히도록 장식 없이 차분하게 구성했습니다.

| 파일 | 크기 | 용도 |
|---|---|---|
| type-panel-960x156.png | 960×156 | 12배 고해상도 소재 |
| type-panel-160x26.png | 160×26 | 2배 소재 |
| type-panel-80x13.png | 80×13 | 기본 타입 패널 크기 |
| type-panel-readability-preview.png | 1024×756 | 빈 패널과 공격·스킬·능력 글자 미리보기 |
| type-panel-original.png | 생성 원본 크기 | 원본 이미지 |
| prompt.txt | — | 실제 생성 프롬프트 |
| asset-info.json | — | 크기, 색상, 투명도 및 미리보기 설정 |

세 가지 소재 PNG에는 글자가 없고 바깥은 투명합니다. 기본 카드 200×260에서 타입 패널 앵커 (0.3, 0.025)~(0.7, 0.075)에 해당하는 80×13 비율로 내보냈습니다. 같은 이미지 위에 타입 글자만 별도로 표시하는 공용 소재입니다.

미리보기는 Noto Sans KR, 검은 굵은 글자, 논리 크기 12, Image 알파 1을 기준으로 한 이미지 조합입니다. 현재 프리팹의 타입 글자 크기는 13이며 이번 작업에서는 변경하지 않았습니다. 미리보기의 글자와 배경은 소재 PNG에 포함되지 않으며 실제 Unity 실행 화면은 아닙니다.

기본 제공 image_gen으로 생성했습니다. 기존 일반 희귀도 이름 패널과 설명 패널은 스타일 참조로만 사용했습니다. 투명 여백을 추출하고 지정 크기로 내보냈습니다. Assets 내 파일, 프리팹과 코드는 변경하지 않았습니다.
