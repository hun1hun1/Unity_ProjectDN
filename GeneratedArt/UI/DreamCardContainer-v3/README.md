# 꿈 카드 컨테이너 v3

꿈 v2의 프레임이 악몽 v2보다 크게 보이고 파란 기운이 줄어든 문제를 수정했습니다. 악몽 v2를 형태 기준으로 사용해 꿈 버전을 다시 생성하고, 양옆 막대와 위쪽 테두리 주변에 푸른 안개를 복원했습니다.

## 파일

- dream-card-container-1728x540.png: 고해상도 UI 소재.
- dream-card-container-864x270.png: 기준 표시 크기.
- dream-card-container-432x135.png: 축소 소재.
- dream-card-container-original.png: 이미지 생성 도구 출력 원본. UI에는 크기와 위치가 정렬된 위의 크기별 PNG를 사용합니다.
- container-alignment-preview.png: 꿈 v3와 기존 악몽 v2 비교. 어두운 배경과 글자는 미리보기에만 포함되어 있습니다.
- prompt.txt: 실제 편집 프롬프트.
- asset-info.json: 크기, 투명도 및 프레임 정렬 측정 결과.

## 정렬과 검증

PNG 전체 크기만 맞추는 대신 철제 막대의 중성색 밝은 픽셀을 기준으로 양옆 위치와 위쪽 수평 테두리 위치를 측정했습니다. 생성 원본을 균일하게 축소하고 투명 캔버스 안에서 이동해 악몽 v2에 맞췄습니다. 1728x540 소재에서 측정된 좌우 막대 위치와 위쪽 테두리 위치의 차이는 각각 0픽셀입니다.

생성된 안개와 금속 장식은 픽셀 단위 복제본이 아닙니다. 밝은 금속 픽셀로 측정한 하단 끝은 악몽보다 약 10픽셀 위이며, 안개 끝은 별도로 부드럽게 사라집니다. 중앙과 바닥 가장자리는 모든 크기에서 알파 0을 확인했습니다.

## 적용

기존 꿈 컨테이너 Image의 Source Image를 크기별 PNG로 교체합니다. 캔버스는 같은 16:5입니다. Sprite Single, Mesh Full Rect, Image Simple, 흰색 Alpha 1, Raycast Target 끄기를 기준으로 합니다. 악몽은 기존 v2를 그대로 사용합니다.

기본 제공 image_gen으로 편집했습니다. 크기 및 위치 정렬과 미리보기 합성만 별도로 처리했으며, 도구가 생성한 파란 기운과 알파를 유지했습니다.

기존 버전과 악몽 v2는 변경하지 않았습니다. Unity 코드, 씬, 프리팹 및 Assets 폴더는 변경하지 않았고 Unity 실행 검증도 수행하지 않았습니다.
