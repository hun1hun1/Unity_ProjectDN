# 공용 HP바 디자인 v1

플레이어와 적이 함께 사용하는 가로형 HP바 이미지입니다. 기존 군인 캐릭터와 카드 테두리의 손으로 그린 질감에 맞춰 어두운 철제 프레임, 얇은 황동색 선, 붉은 체력 채움으로 구성했습니다. 특정 진영의 문양은 사용하지 않았습니다.

## 파일

| 파일 | 크기 | 용도 |
|---|---|---|
| `hp-frame.png` | 1072×120 | 중앙이 투명한 금속 테두리 |
| `hp-track.png` | 976×76 | 빈 체력 영역의 어두운 바탕 |
| `hp-fill.png` | 976×76 | 수평으로 줄어드는 붉은 체력 채움 |
| `hpbar-full.png` | 1072×120 | 체력 100% 상태의 조합 이미지, 숫자 없음 |
| `hpbar-preview.png` | 1168×552 | 100%·60%·25% 상태의 배치 미리보기 |
| `hpbar-source-atlas.png` | 1536×1024 | 생성 원본 |
| `asset-info.json` | — | 크기, 레이어 배치 및 알파 검사 결과 |
| `prompt.txt` | — | 실제 생성 프롬프트 |

재사용 소재 3종과 조합 이미지는 투명 배경 PNG입니다. 미리보기에는 가독성 확인용 배경과 HP 숫자가 포함되어 있으며, 개별 소재에는 숫자가 없습니다.

## 레이어 배치 기준

1072×120 캔버스에서 빈 바탕과 붉은 채움을 왼쪽 위 기준 `(48, 22)`에 놓고, 테두리를 맨 위에 겹칩니다. 붉은 채움은 가로 폭을 축소해 압축하기보다 왼쪽부터 표시 영역을 잘라 체력 비율을 나타내는 방식에 맞춰 제작했습니다.

현재 일반 캐릭터 프로필의 정보 UI는 320×84이며, 기존 HPBar 앵커 영역은 약 262.4×29.4입니다. 테두리를 이 영역에 맞춰 배치할 때 내부 영역의 비율은 대략 가로 91.04%, 세로 63.33%이며, 중심은 수평 중앙·상단에서 50%입니다. 최종 픽셀 반올림은 실제 배치 크기에 맞춰 조정합니다.

원본 도색 이미지는 기본 제공 `image_gen`으로 생성했습니다. 이후 소재 행 추출, 크기 조정 및 레이어 조합을 진행했습니다. 테두리의 중앙 알파 0과 각 소재의 투명 배경을 검사하고 조합 이미지를 확인했습니다.

디자인 제작 후 2026-10-22에 프로젝트에도 적용했습니다. `Assets/Images/UI/CharacterHUD`에 원본과 같은 이미지가 들어 있으며, 공용 크기별 HUD와 기존 캐릭터 프리팹에서 사용합니다. `ProjectDN/Apply Shared HUD Artwork` 메뉴는 해당 원본을 다시 가져와 같은 배치로 적용합니다.
