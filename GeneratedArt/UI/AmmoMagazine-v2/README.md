# 촘촘한 탄창·탄약 UI v2

탄약이 서로 거의 맞닿도록 쌓이는 버전입니다. 단일 탄약의 가늘고 긴 형태는 그대로 유지하고, 한 발의 배치 간격을 기존 90픽셀에서 26픽셀로 줄였습니다. 10발이 들어가는 내부 높이는 900픽셀에서 260픽셀로 줄어들었으며 탄창도 이에 맞는 짧은 형태로 다시 제작했습니다.

## Fill 배치

280×420 탄창에서 Fill 영역은 왼쪽 52, 위쪽 84, 너비 176, 높이 260입니다. 부모 탄창 기준 Anchor Min (0.1857143, 0.1809524), Anchor Max (0.8142857, 0.8), Offset 네 방향 0으로 대응합니다. Filled / Vertical / Bottom, Fill Amount current / 10 기준입니다. 0~10발에서 한 발 단위 경계가 탄약을 자르지 않고 올바른 수를 표시하는 것을 이미지 수준에서 확인했습니다.

v2는 탄창과 Fill을 함께 사용해야 합니다. 원형 탄약의 가늘고 긴 비율을 유지하기 위해 전체 탄창 비율이 기존 70×270에서 70×105로 바뀌었습니다. Unity에 적용할 때 기존의 긴 패널에 이미지를 세로로 늘리면 탄약도 늘어나므로 새 비율로 표시해야 합니다. 이번 작업에서는 씬의 패널 크기나 UI 코드를 변경하지 않았습니다.

이 Fill은 최대 10발 기준입니다. 최대 장탄 수가 달라지면 반복 셀 개수나 Fill 이미지를 해당 개수에 맞춰 구성해야 합니다.

짧은 탄창은 기본 제공 image_gen으로 v1을 참조해 제작했습니다. 단일 탄약은 v1의 생성 PNG를 그대로 재사용했고, 투명 여백 정리·크기 조정·반복 배치로 새 Fill을 만들었습니다. 이전 v1 파일은 유지했습니다. 실제 Unity 실행 검증은 진행하지 않았습니다.
