# 꿈·악몽 카드 더미 UI v1

참고 스케치처럼 평평하게 놓인 카드 더미를 비스듬히 내려다보는 투명 배경 이미지 4종입니다. 기존 카드의 문양, 색감과 거친 도색 질감을 사용했습니다. 꿈과 악몽은 서로 마주 보는 방향이며, 뽑을 더미는 정돈된 뒷면, 버린 더미는 약간 어긋난 고정 앞면입니다. 글자와 장수는 그림에 포함하지 않았습니다.

| 종류 | 512×512 | 128×128 |
|---|---|---|
| 꿈 뽑을 더미 | `dream-draw-pile-512x512.png` | `dream-draw-pile-128x128.png` |
| 꿈 버린 더미 | `dream-discard-pile-512x512.png` | `dream-discard-pile-128x128.png` |
| 악몽 뽑을 더미 | `nightmare-draw-pile-512x512.png` | `nightmare-draw-pile-128x128.png` |
| 악몽 버린 더미 | `nightmare-discard-pile-512x512.png` | `nightmare-discard-pile-128x128.png` |

각 종류의 `*-original.png`는 생성 원본이며, `*-prompt.txt`에는 실제 프롬프트를 저장했습니다. 기본 제공 `image_gen` 도구로 제작했습니다. 꿈 카드 더미 2종을 만든 뒤 그 구도와 기존 악몽 카드의 색·문양을 참조해 악몽 버전을 편집했습니다.

원본과 투명도를 보존하고 정사각형 캔버스 전체를 Lanczos 방식으로 축소했습니다. 모서리를 자르거나 별도 배경을 합성하지 않았습니다. 원본과 출력 PNG의 크기, RGBA 모드, 투명한 모서리와 알파 범위를 확인했으며 상세 정보는 `asset-info.json`에 있습니다.

이 작업은 이미지 제작 범위입니다. Unity 씬·프리팹·게임 데이터 및 툴팁 동작은 변경하지 않았습니다.
