# 카드 설명 패널 v1

회베이지색의 낡은 군용 문서 종이 느낌으로 제작한 공용 설명 패널입니다. 중앙은 검은 한글 설명을 읽기 쉽도록 밝고 차분하게 두고, 가장자리에 종이의 마모와 얇은 금속빛 윤곽을 배치했습니다. 꿈·악몽 및 희귀도에 관계없이 함께 사용할 수 있는 중립색입니다.

| 파일 | 크기 | 용도 |
|---|---|---|
| description-panel-1080x468.png | 1080×468 | 6배 고해상도 소재 |
| description-panel-360x156.png | 360×156 | 2배 소재 |
| description-panel-180x78.png | 180×78 | 기본 설명 패널 크기 |
| description-panel-readability-preview.png | 1144×1040 | 빈 패널과 설명 문구 가독성 미리보기 |
| description-panel-original.png | 생성 원본 크기 | 원본 이미지 |
| prompt.txt | — | 실제 생성 프롬프트 |
| asset-info.json | — | 크기, 색상 및 투명도 측정 |

소재 PNG에는 글자와 문양이 없으며 외곽은 투명합니다. 카드 기본 크기 200×260, DescriptionPanel 앵커 (0.05, 0.1)~(0.95, 0.4)에 해당하는 180×78 비율로 내보냈습니다.

가독성 미리보기는 Noto Sans KR, 검은 굵은 글자, 논리 크기 12 및 Image 알파 1을 기준으로 한 이미지 조합입니다. 미리보기 글자는 소재에 포함되지 않습니다. 실제 Unity 실행 화면은 아닙니다. 현재 프리팹 설명 배경의 알파 0.392를 유지하면 카드 배경과 혼합되어 결과가 달라집니다.

기본 제공 image_gen으로 생성했습니다. 일반 희귀도 이름 패널과 꿈 카드 앞면은 스타일 참조로만 사용했습니다. 생성 후 투명 여백을 추출하고 지정 크기로 내보냈습니다. 프리팹, 코드 및 Assets 내 이미지는 변경하지 않았습니다.
