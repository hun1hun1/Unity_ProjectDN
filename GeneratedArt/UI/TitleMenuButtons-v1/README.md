# Dream&Nightmare 타이틀 버튼 디자인 v1

남청색 패널과 은빛 프레임을 사용하는 문구 없는 공용 버튼 이미지이다.
내장 image_gen 도구로 제작하였으며 PNG의 외부 여백은 실제 알파 투명도를 가진다.

## 파일 구성

| 파일 | 용도 |
|---|---|
| title-button-normal.png | 일반 메뉴 버튼의 기본 상태 |
| title-button-selected.png | 마우스를 올리거나 키보드로 선택한 상태 |
| title-button-pressed.png | 누르고 있는 상태 |
| title-button-disabled.png | 사용 불가 상태, 붉은 확인 버튼에도 공용 사용 |
| title-confirm-red-normal.png | 종료 확인창의 확정 버튼 기본 상태 |
| title-confirm-red-selected.png | 종료 확정 버튼의 마우스 올림 / 키보드 선택 상태 |
| title-confirm-red-pressed.png | 종료 확정 버튼의 누름 상태 |
| title-selection-diamond.png | 선택한 메뉴 왼쪽에 표시하는 별도 마름모 |

## 디자인 적용 기준

- 이어서 하기, 게임 시작, 튜토리얼, 옵션, 게임 종료 메뉴는 같은 남청색 버튼을 사용한다.
- 붉은 버튼은 종료 확인창의 확정 동작에 사용한다.
- 문구는 이미지에 포함하지 않고 TextMeshPro 등 별도 텍스트로 표시한다.
- 한글은 Hahmlet SemiBold, 글자는 밝은 은백색을 기준으로 한다.
- 선택된 메뉴에만 별도 마름모를 표시한다. 버튼의 양 끝 장식과는 별개의 선택 표시이다.
- 로고 아래에 세로로 정렬하고 최대 5개 메뉴를 위한 공간을 확보한다.

## 원본과 연결 상태

PNG는 투명 여백을 포함하는 생성 원본이다. 공용 버튼 원본은 2172×724이며
누름 및 붉은 선택 원본은 가로가 1픽셀 작은 2171×724이다.
마름모 원본은 1254×1254이다. 각 상태의 그림은 생성 편집으로 제작되어
픽셀 단위로 동일한 실루엣을 보장하는 상태 시트는 아니다.

380×68 정도의 화면 표시 크기는 투명 여백을 제외한 버튼 영역을 기준으로 한다.
Unity에서 사용할 때에는 스프라이트 영역과 기준점을 맞춰 투명 여백이 표시 크기에
포함되지 않도록 구성한다. 이 산출물에는 Unity 임포트 설정, Sprite Rect,
9-slice 경계값, 씬 연결 또는 상태 전환 구현을 포함하지 않는다.

generation-prompts.json에 실제 생성·편집 프롬프트를 기록하였다.
asset-manifest.json에 각 이미지의 크기와 알파 샘플 검사 결과를 기록하였다.
