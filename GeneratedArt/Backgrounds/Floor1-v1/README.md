# 1층 전투 배경 v1 — 현실과 꿈의 경계

비가 그친 해 질 무렵, 안개가 스며드는 마을 외곽길입니다. 젖은 흙길과 돌바닥, 나무 울타리, 작은 창고, 전신주와 먼 마을을 배치했습니다. 현실적인 풍경을 중심으로 하면서 물웅덩이에만 푸른 초승달이 비치고, 먼 전신주가 조금 기울어진 작은 이상 현상을 넣었습니다. 하늘에는 달이 없습니다.

캐릭터가 대치할 수 있도록 중앙의 길을 넓게 비웠고, 먼 풍경은 안개로 단순하게 정리했습니다. 하단은 카드 UI를 위한 어두운 땅으로 구성했습니다. 그림에는 캐릭터나 UI가 포함되어 있지 않습니다.

## 파일

| 파일 | 용도 |
|---|---|
| floor1-battle-background-1920x1080.png | 16:9 적용용 PNG |
| floor1-battle-background-1280x720.png | 축소 소재 |
| floor1-battle-background-preview.png | 960x540 미리보기 |
| floor1-battle-background-original.png | 1672x941 생성 원본 |
| prompt.txt | 실제 생성 프롬프트 |
| asset-info.json | 치수와 제작 정보 |

1920x1080 버전은 생성 원본을 약 1.15배 확대한 내보내기입니다. 원본 비율을 유지해 16:9로 맞췄으며 투명 외곽 여백은 없습니다. 원본도 그대로 포함했습니다.

## 제작 및 표시 범위

기본 제공 image_gen으로 제작했습니다. 기존 군인과 허수아비 이미지는 그림체와 색감의 참조로만 사용했습니다. 크기별 리사이즈와 PNG 내보내기만 별도로 처리했습니다.

전체 화면용 16:9 배경입니다. 기존 BattleArea는 전투 캐릭터의 배치 영역이므로 그 영역 자체의 가로세로 비율과는 다릅니다. 실제 적용 시 전체 화면 배경 Image에서 캐릭터 및 UI보다 뒤에 표시하는 것을 기준으로 합니다.

내보낸 이미지의 치수와 불투명 PNG 여부를 검사했습니다. Unity 코드, 씬, 프리팹 및 Assets 폴더는 변경하지 않았습니다. 실제 플레이 화면의 캐릭터 겹침이나 해상도 변경 검증은 수행하지 않았습니다.
